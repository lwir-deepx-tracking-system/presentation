# 공통 디자인·참고자료

- [발표 개요와 전체 제작 규칙 — Notion](https://app.notion.com/p/4169de3f14a280ee9e05cec320dfb929)
- 공통 사진은 **`picture/`**에 둡니다. 기존 `human/`에서 경로가 바뀌었습니다.
- `picture/hardware.png`: 실제 하드웨어 사진.
- `picture/윤오름.png` 등 팀원 이름의 PNG 5개: 팀 소개 사진.
- 현재 통합 작업본 [C안](../work/C/README.md)은 위 사진을 자체 assets로 복사하고, 재생성할 때 공통 사진을 동기화합니다.
- 최신 통합 발표의 디자인·헤더·표지 기준은 [work/DESIGN.md](../work/DESIGN.md)를 우선합니다.

## 헤더와 로고

- 좌측 상단에 제목, 우측 상단에 제공된 공식 LIG 로고를 배치합니다.
- 현재 통합본 제목은 **50px**, 로고 높이는 **34px**입니다. 원본 비율과 색상을 유지합니다.
- 로고 중심을 헤더와 맞추고 오른쪽 끝은 본문 오른쪽 여백 84px에 맞춥니다.
- 로고 영역은 다른 콘텐츠와 겹치지 않게 합니다.
- 하단에는 오른쪽 페이지 번호만 표시합니다. 출처는 대본·출처 문서에 보존합니다.

## 작성·출력

- 각자 HTML/CSS를 독립적으로 만들어도 됩니다. 공통 디자인 규격은 유지합니다.
- 슬라이드는 `<section class="slide">`로 구분합니다.
- 작은 화면에서는 미리보기만 비례 축소하고 원본 캔버스는 FHD로 유지합니다.
- PDF 한 페이지에 슬라이드 한 장을 출력하며, 잘림과 폰트·이미지 누락을 확인합니다.
- 그림과 표에는 출처·단위·비교 조건을 적습니다.
- 애니메이션 없이도 핵심 내용이 보여야 합니다.
- 규칙이 변경되면 Notion과 이 안내를 함께 갱신합니다.
