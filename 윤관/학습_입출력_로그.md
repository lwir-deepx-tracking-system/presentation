# 모델별 학습 입력·출력과 기록

발표 10·18~20·23쪽의 보충 설명이다. 학습 데이터와 정답, 모델의 예측, 학습 후 평가 기록을 구분했다. 실제 기기용 입력과 양자화 보정 자료는 별도 과정이다.

## 검출: YOLO26

- **왜:** 열화상에서 사람의 위치를 찾기 위해 COCO 사전학습 모델을 FLIR에 맞춰 다시 학습했다.
- **입력·정답:** 640×640 열화상 이미지와 사람·차량 등 클래스 및 상자. **예측:** 상자 위치와 클래스 점수.
- **실제 학습 로그:** [FT](학습로그/YOLO26s_FT_seed101.csv), [LoRA](학습로그/YOLO26s_LoRA_seed101.csv), [학습률 조정 LoRA](학습로그/YOLO26s_LoRA_lr1e-3_seed101.csv). YOLO26s, seed 101, batch 4, 각각 30 epoch인 별도 실험이다. 발표의 실제 FT·LoRA 검증 곡선에 사용된 세 CSV이며 원본 해시가 당시 manifest와 일치함을 확인했다.
- **60 epoch 검출기 증류 원본:** [YOLO26s 직접 FT](학습로그/YOLO26s_FT_60epoch_seed202.csv) · [YOLO26m→s 증류](학습로그/YOLO26s_KD_60epoch_seed202.csv). 둘 다 FLIR 4,196장·seed 202이며, 평가 기록의 최종 체크포인트와 결과를 대조했다. 증류 로그 `train/dis_loss`는 1 epoch 8.77978 → 60 epoch 1.45011. 검증 사람 AP50–95는 FT 44.8575%, 증류 44.2334%로, 학습 손실 감소와 검증 성능은 다른 값이다.
- **로그 읽기:** `epoch`는 학습 회차, `train/box_loss`·`train/cls_loss`는 훈련 중 상자·분류 손실, `val/box_loss`·`val/cls_loss`는 검증 손실이다. `monitor_primary6/mAP50_95`는 6개 클래스의 검증 지표, `lr/pg0` 등은 학습률이다. 손실과 AP는 의미와 방향이 다르다. 검출기 소형 후보 결과의 YOLO26m과 이 YOLO26s 로그는 같은 실행이 아니다.

## 자세: YOLO26m-pose

- **왜:** 사람의 관절과 상체를 찾아 가림과 크기 변화가 있는 장면에 대응하기 위해 공개 열화상·흑백·겹침 자료를 단계적으로 활용했다.
- **입력·정답:** 열화상 또는 흑백 이미지와 사람 상자, 관절 17점 및 보임 상태. **예측:** 사람 상자와 관절 위치. 장치 기본 검출 파일은 상자·종류 6출력이고, 관절 파일은 관절 3출력이 더해져 9출력이다.
- **확인한 결과:** OTP2의 관절 AP, TMOT의 추적 HOTA와 거리별 검출률은 서로 다른 평가다. 해당 발표 대상 자세 실험의 원본 epoch별 loss 파일은 확인하지 못했다. [프로젝트 학습 기록](https://github.com/lwir-deepx-tracking-system/model-bank/blob/6cf676df1c1be72bd6e8220a6240a0d3f1c7127e/tracking_server/research/lwir_pose_plan/README.md)

## 외형: SOLIDER → RepVGG

- **왜:** 사전학습 교사의 사람 표현을 장치에서 실행할 수 있는 작은 모델에 전달해 보려 했다.
- **입력·정답:** 사람 이미지 crop과 신원 라벨. **예측:** RepVGG의 128차원 외형 특징. 특징 간 유사도를 사용해 재연결을 돕는다.
- **확인한 결과:** OTP2 사람 검색 Rank-1, TMOT·CAMEL 검색 결과, 교사와 학생의 종합 점수를 각각 시험 조건에 맞춰 확인했다. 해당 증류 실험의 원본 epoch별 loss 파일은 미확인이다. [외형 모델 기록](https://github.com/lwir-deepx-tracking-system/model-bank/blob/6cf676df1c1be72bd6e8220a6240a0d3f1c7127e/tracking_server/models/README.md#L312-L346)

## 위치 기억: GRU

- **왜:** 가림 때문에 사람 검출이 끊기는 동안 추적 위치를 예측하기 위해서다.
- **입력:** 프레임당 68차원으로 상자·속도 등 16값, 17개 관절의 상대 좌표·보임 51값, 유실 단계 1값. 최신 GRU는 화면 가장자리 4값을 고정했다. **학습:** 검출 결과로 30 epoch, val-A에서 29 epoch 선택. **출력:** 카메라 이동을 반영한 Kalman 예측의 위치·크기 보정값.
- **확인한 결과:** 14편의 놓침 위치 오차와 별도 한 편의 IDF1·ID 변경 횟수를 구분했다. 그 결과와 짝을 이루는 원본 학습 loss 로그는 확인하지 못했다. [위치 기억 구현](https://github.com/lwir-deepx-tracking-system/model-bank/blob/6cf676df1c1be72bd6e8220a6240a0d3f1c7127e/tracking_server/src/track/position_memory.py)

## Mamba 위치 기억

- **왜:** GRU와 다른 시계열 모델의 위치 예측을 비교하기 위해서다. **입력·출력:** 상자와 관절 시계열에서 유실 중 위치 보정값을 예측한다.
- **확인한 결과:** 재학습 전후 위치 오차 0.361→0.127; 같은 시험 Kalman 0.110, GRU 0.122. 시험 데이터는 개발에도 사용됐다. 해당 실행의 epoch별 손실 로그는 확인하지 못했다. [위치 기억 인계 기록](https://github.com/lwir-deepx-tracking-system/model-bank/blob/6cf676df1c1be72bd6e8220a6240a0d3f1c7127e/HANDOFF.md)

## FastTrackTr

- **왜:** 탐지와 시간 정보를 함께 이용한 ID 연결을 시험하기 위해서다.
- **입력:** 현재 프레임과 과거 특징. 학습은 DanceTrack 흑백 후 TMOT 열화상과 DanceTrack 일부로 이어졌다. **출력:** 사람 상자와 ID 단어; 서버가 ID 단어를 연결에 사용한다.
- **확인한 결과:** 녹화별 IDF1·재현율, M1 단계 시간을 확인했다. 28ms는 겹쳐 실행한 단계 시간이며 화면까지의 종단 지연이 아니다. 원본 epoch별 loss 파일은 이번 근거에서 확인하지 못했다. [모델 INFO](https://github.com/lwir-deepx-tracking-system/model-bank/blob/6cf676df1c1be72bd6e8220a6240a0d3f1c7127e/tracking_server/models/e2e/fasttracktr/INFO.json)
