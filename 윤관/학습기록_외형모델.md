# 학습 기록 · 외형(ReID) 모델

발표자가 "왜 했고, 어떤 데이터로, 어떤 순서와 설정으로, 결과가 어땠는지"를 질문받았을 때 바로 답하도록 모은 글입니다. 숫자마다 출처를 붙였습니다. 출처 표기는 두 가지입니다. 공개 저장소의 `model-bank <커밋> <파일>`과, 비공개 학습 서버·PC에 남은 기록을 가리키는 `개인 실험 기록(<파일 이름>)`입니다. 기록이 남아 있지 않은 것은 "기록 없음"으로 적었습니다. 손실 곡선 원본은 [학습로그](학습로그/) 폴더의 `외형_*.csv`입니다. 그림은 부록 장 `외형 모델 시도 순서`, `증류 학습 설정`, `외형 모델 손실 곡선`에 있습니다.

## 1. 11-10 실내 교사·학생 학습 (RepVGG 증류·직접, 내부 이름 r7)

**왜 했나.** 사용자 요청 문장은 기록 없음. 사전 등록 문서의 목적 문장은 "우리 카메라 실내 검수 영상 5편으로 외형 모델을 학습하되, 직접 미세조정(D)과 교사를 먼저 미세조정한 뒤 증류(S)를 같은 시험에서 비교한다"입니다. 결과 파일은 장치에서 도는 RepVGG와 같은 입출력 규격이어야 한다는 조건이 붙었습니다. 출처: 개인 실험 기록(PREREG_REID_FT7.json).

**데이터.** 우리 카메라 실내 검수 영상 5편. 각 영상의 앞 70%를 학습, 다음 15%를 검증(선택용), 마지막 15%를 시험(한 번만)으로 나눴습니다.

| 구간 | 프레임 | 사람 조각 | 빈 박스 조각 | 신원 수(영상별 합) |
| --- | ---: | ---: | ---: | ---: |
| 학습 | 994 | 1,847 | 1,829 | 15 |
| 검증 | 163 | 227 | 490 | 14 |
| 시험 | 167 | 305 | 370 | 13 |

공개 조각 6,000장은 "원래 배운 것을 잊지 않게" 붙잡는 용도로만 썼습니다(TMOT·CAMEL·FLIR 학습 조각). 출처: 개인 실험 기록(PREREG_REID_FT7.json).

**선생과 학생.** 선생은 SOLIDER Swin-Tiny(입력 384×128, 768차원)입니다. 이 선생은 공개된 열화상 재식별 가중치(ThermalTrack, VT-MOT·PT-MOT로 이미 열화상 재식별 학습이 된 것)이고, 11-20 파인튜닝의 시작점(LUPerson 자기지도 원본)과는 다른 파일입니다. 학생은 장치에서 도는 RepVGG-A0(128차원)입니다. 출처: 개인 실험 기록(PREREG_REID_FT7.json, PREREG_SOLIDER_FT.json 참조 행).

**학습 순서와 설정.**
1. 선생 미세조정(T): 6가지(lr 1e-4·3e-4·1e-3 × 기억 고정 anchor 0·2), 8 epoch × 50 step(= 400 step). SGD(momentum 0.9, weight decay 1e-4). 손실 = 배치 안에서 가장 어려운 짝을 찾는 triplet(마진 0.3, 같은 영상의 다른 사람·빈 박스가 부정 예) + anchor × (공개 조각에서 시작 선생과 특징 차이).
2. 학생 직접(D)과 증류(S): 각각 8가지(lr 1e-5·3e-5·1e-4·3e-4 × anchor 0·2), 8 epoch × 50 step. AdamW(weight decay 0.05), 배치 정규화 통계 고정. D의 손실 = 같은 triplet + anchor 항. S의 손실 = (1 − cos(학생, 선생 특징을 128차원으로 줄인 목표)) + 1.0 × RKD-D(거리 관계 맞추기) + anchor 항.
3. 선택은 검증 점수만 씁니다(점수 = (rank-1 + AUC) / 2). 시험은 한 번만.

**손실·검증 곡선.** 선생 선택 run(T lr 3e-4, anchor 2): 학습 손실 0.388(1 epoch) → 0.116(8), 검증 점수 0.901(시작) → 0.955(3 epoch) → 0.947(8). D 선택 run(lr 3e-4, anchor 2): 손실 0.301 → 0.034, 검증 0.813 → 0.933(6 epoch). S 선택 run(lr 3e-4, anchor 0): 손실 0.357 → 0.131, 검증 0.813 → 0.944(5 epoch). 전체 곡선: [외형_11-10_실내_epoch별.csv](학습로그/외형_11-10_실내_epoch별.csv).

**결과(시험 구간, 한 번).**

| 모델 | 점수 |
| --- | ---: |
| 장치 학생(시작) | 0.949 |
| D 선택(lr 3e-4, 6 epoch) | 1.000 (+0.051, 95% 구간 0.037~0.068) |
| S 선택(lr 3e-4, 5 epoch) | 0.996 (+0.047, 0.033~0.063) |
| 선생 시작 / 선택 | 0.976 / 0.996 |

**왜 이 숫자를 크게 믿지 않나.** 검증·시험 구간은 같은 방, 같은 옷, 학습 구간 바로 뒤 몇 초입니다. 한 사람이 나갔다 돌아오는 경우가 없어서, 이 점수는 "이 녹화 속 사람끼리 구분"이지 "새로운 날·새로운 방"이 아닙니다. 사전 등록에도 이 한계가 적혀 있습니다. 기록은 장치 INT8 정확도를 재지 않았습니다. 출처: 개인 실험 기록(TEST_RESULT.json, SELECT_FINAL.json, SELECT_TEACHER.json, 학습 로그).

**결정.** 모델뱅크에 시험용으로만 올렸습니다(모델 파일 이름 `RepVGG_distillation_(실내)_20261110`, `RepVGG_fine-tuning_(실내)_20261110`). 두 파일이 위의 S·D에 각각 해당하는 것으로 보이나(추정), 변환 단계 기록은 이 자료에 없습니다. 출처: model-bank b20d481 tracking_server/models/README.md (3. 외형 비교).

## 2. 11-11 ViT-lite 실내 2종 (증류·미세조정)

**왜 했나.** 기록 없음. 이 PC·학습 서버·모델뱅크 어디에도 11-11 학습 코드와 가중치는 없습니다. 11-13에 "원래 ViT-lite 학습 파일을 못 찾았다"고 작업 기록부에 적혀 있습니다(개인 실험 기록: 작업 기록부 2026-11-13 22:55). 10-23의 첫 ViT-lite는 "SOLIDER 교사 → FLIR 사람 조각 KD 학생, 128×64, NPU 3.0 ms"로 소개되어 있습니다(model-bank 2930ece README).

**알려진 것.** 모델뱅크는 두 파일을 "teacher SOLIDER, 우리 카메라 실내"(증류), "우리 카메라 실내"(미세조정)로 적고, 학습 장 수와 PC 평가값은 "이 저장소에 기록이 없다"고 적었습니다. 파일 1.46 MB, 마지막 층만 파일 안 CPU입니다(model-bank b20d481 tracking_server/models/README.md, reid/README.md).

**11-20 장치 채점(이 모델들의 유일한 숫자).** 같은 조각을 Orange Pi M1 NPU에 한 장씩 넣어 1위 정답률을 쟀습니다. 조각 처리 약 5.0 ms(RepVGG는 1.3 ms).

| 모델 | OTP2 몸 | OTP2 가림 | 실내 몸 | 실내 가림 |
| --- | ---: | ---: | ---: | ---: |
| ViT-lite 미세조정(11-11) | 0.616 | 0.592 | 0.989 | 0.903 |
| ViT-lite 증류(11-11) | 0.672 | 0.596 | 0.915 | 0.841 |
| RepVGG FT OTP2(11-13) | 0.892 | 0.834 | 0.977 | 0.847 |
| RepVGG 검수 264장(11-17) | 0.764 | 0.667 | 1.000 | 0.892 |

주의: 실내 열은 질의 176개라 1개 차이가 0.6%p이고, ViT-lite 두 개와 검수 264장 모델이 이 실내 녹화를 학습에 썼는지 확인하지 못했습니다. 그래서 실내 열은 부풀었을 수 있고, OTP2 열(시험 신원이 어떤 모델 학습에도 없음)이 더 공정합니다. 출처: 개인 실험 기록(reid_vitlite_eval_20261120 RESULT.md, RESULT.json).

**결정.** 시험용으로만 올렸고 기본 모델은 바뀌지 않았습니다. 이유는 위 표에서 OTP2 기준 RepVGG보다 낮고 NPU 시간이 약 4배 걸리기 때문입니다.

## 3. 11-13 근거리 외형 모델 묶음 (Vast GPU 한 대, 같은 날)

공통 상황: 근거리용 "몸 박스(머리~골반)" 검출기를 새로 만들었고, 그 박스에서 자른 조각은 아래쪽이 잘리거나 책상·다른 사람에 가려진 것이 많아서, 전신 사람으로만 학습한 기존 외형 모델이 잘 맞지 않을 수 있다는 문제의식이 출발점이었습니다. 출처: 개인 실험 기록(reid_partial.py 머리말, 작업 기록부 2026-11-13 20:50).

평가 점수는 모두 (rank-1 + AUC) / 2이고 "전체, 몸 박스, 잘림, 가림" 보기를 따로 셉니다. OTP2 시험은 60명·질의 537개, 우리 실내 검증·시험은 11-10 구간입니다.

### 3-1. RepVGG 1차 자기증류 (reid_partial)

- **왜:** 사용자 "같이해 학습"(근거리 검출기 학습과 함께 하라는 뜻으로 보임). 신원 정답 없이, 전체 조각을 보는 자기 자신을 선생으로 삼아 몸 박스·잘림·가림 보기에서도 같은 특징을 내게 하는 방법.
- **데이터:** 공개 열화상 조각 54,586장(TMOT·CAMEL·FLIR). 우리 실내는 평가만.
- **설정:** 12,000 step, 배치 256, lr 3e-4(cosine), 손실 = (1 − cos(보기, 선생 전체)) + 0.5 × (1 − cos(학생 전체, 선생 전체)) + RKD. 32분.
- **곡선:** 보기 손실 0.300(500 step) → 0.124(12,000). 실내 검증(몸) 0.754(3,000) → 0.716(12,000).
- **결과(실내 검증 시작 → 끝):** 전체 0.813 → 0.787, 몸 0.787 → 0.716, 잘림 0.720 → 0.715, 가림 0.754 → 0.751. 학습 손실은 내려가는데 우리 영상 점수는 내려갔습니다.
- **결정:** 배포 안 함. 출처: 개인 실험 기록(TRAIN_LOG reid_partial_v1, 작업 기록부 2026-11-13 21:27).

### 3-2. RepVGG + OTP2 실제 신원 triplet (채택)

- **왜:** 사용자 "26m 학습처럼 그 데이터로"(검출기를 OTP2로 학습한 것처럼 외형도 OTP2로). OTP2 실내 앉은 사진은 파일 이름 앞 숫자가 사람, 두 번째가 회차(옷이 다름)여서 진짜 신원 라벨로 쓸 수 있음을 그림으로 확인했습니다.
- **데이터:** OTP2 train 200신원(사람+회차) 3,563장, val 24, test 60. 분할 사이에 같은 사람 없음. 조각은 몸 박스를 화면 안으로 자르고 64×128로 늘린 것, 잘림·가림·흐림·밝기·잡음 보기를 학습에 추가.
- **설정:** 시작 = 11-03 공개 열화상 증류 RepVGG-A0, 3,000 step, 배치 P32×K4(32명×4장), lr 1e-4 cosine, 손실 = batch-hard triplet(마진 0.3) + 0.5 × 시작 모델과의 코사인 차이(공개 조각, 원래 특징과 눈금을 지키려는 용도). 5.6분.
- **곡선:** 손실 0.505(250 step) → 0.308(3,000). 이 triplet 값은 모든 실행에서 0.30 근처에 머무는 값이라 곡선 모양만 보고 판단하지 않았고, 아래 점수로 판단했습니다. OTP2 검증(전체) 0.912(1,000) → 0.930(3,000).
- **결과(시험):** OTP2는 rank-1로 전체 0.724 → 0.890, 잘림 0.184 → 0.272, 가림 0.652 → 0.840. 우리 실내는 점수((rank-1 + AUC) / 2)로 전체 0.949 → 0.925, 몸 0.915 → 0.918.
- **결정:** 모델뱅크 업로드와 장치 반영(`REPVGG_FT_OTP2_20261113`). 11-20에 서로 다른 사람끼리도 유사도가 약 0.99로 나와 번호 잇기에 쓸 수 없어 삭제(model-bank b20d481 tracking_server/models/README.md). 출처: 개인 실험 기록(TRAIN_LOG reid_otp2_v1, 작업 기록부 2026-11-13 21:27, 21:50).

### 3-3. DeiT-Tiny ViT (사용자 "Vit도 해야해")

- **왜:** 원래 ViT-lite 학습 파일을 못 찾아서, 같은 계열을 새로 만들어 보려 했습니다.
- **구조·데이터:** timm DeiT-Tiny(ImageNet 사전학습, 5.5 M 파라미터), 입력 128×64, CLS → LayerNorm → Linear(192, 128). 선생 = 3-2의 RepVGG(KD 1.0). 데이터는 3-2와 같은 OTP2 3,563장.
- **설정:** 4,000 step, 배치 P32×K4, lr 2e-4 cosine, 손실 = KD 1.0 + triplet 0.3. 7.7분.
- **곡선:** KD 0.092(250) → 0.0055(4,000). 실내 검증(몸) 0.826(1,000) → 0.690(4,000)으로 학습할수록 내려갔습니다.
- **결과(시험):** OTP2 전체 rank-1 0.747(RepVGG 0.890), 실내 몸 점수 0.783(RepVGG 0.918).
- **결정:** 모든 칸이 RepVGG보다 낮아 폐기. M1 변환 자체는 가능했습니다(적극적 분할). 출처: 개인 실험 기록(TRAIN_LOG vit_ft_otp2_v1, 작업 기록부 2026-11-13 22:55, 23:09).

### 3-4. 작은 ViT-Lite 새로 (사용자 "Repvgg처럼")

- **구조:** 블록 2개, 차원 192, 헤드 4, 패치 8, 모든 층을 1×1 합성곱·배치정규화로 만든 68만 파라미터. 장치의 원래 ViT-lite 파일에서 읽은 구조를 따라 만들었습니다.
- **설정:** 15,000 step, lr 1e-3, 공개 조각 배치 256 + OTP2 P32×K4. 손실 = RepVGG 특징 복사 + RKD + triplet.
- **곡선(2,500 step까지):** 손실 0.767(500) → 0.327(2,500), KD 0.259 → 0.0067.

### 3-5. PMT ViT-Base (근적외선 공개 가중치)

## 8. 회의에서 받을 만한 질문 10개

1. **ViT를 왜 버렸나?** 같은 OTP2 학습에서 DeiT-Tiny는 모든 칸이 RepVGG보다 낮았고, PMT ViT-Base는 OTP2는 최고(전체 0.952)지만 우리 실내가 0.925 → 0.864로 떨어졌고, ViT-lite는 장치에서 약 4배 느렸습니다(5.0 vs 1.3 ms).
2. **PMT는 왜 우리 영상에서 나빠졌나?** 1,000 step에서 실내 점수가 최고(0.904)였다가 학습할수록 OTP2 쪽으로 맞춰지며 내려갔습니다. 원인을 따로 실험으로 가르지는 않았고 곡선으로 본 해석입니다.
3. **증류가 왜 직접 학습보다 못했나?** 11-15에서 학습 손실은 거의 0인데 목표가 이미 학생과 같았습니다(옛 128차원 변환이 안 맞아 능선 회귀로 바꾼 것). 11-10에서는 S가 D와 비슷하게 좋았습니다(0.996 vs 1.000).
4. **11-10의 0.99대 점수를 믿어도 되나?** 아닙니다. 같은 방·같은 옷의 학습 바로 뒤 몇 초이며, 새 날·새 방 검증이 아닙니다.
5. **triplet 손실이 0.30 근처에서 멈춘 건 학습이 안 된 것 아닌가?** 마진 0.3의 batch-hard 값은 모든 실행(채택한 RepVGG 포함)에서 0.30 근처였고, 판단은 검증 점수로 했습니다. 손실 곡선만으로는 좋고 나쁨을 가릴 수 없습니다.
6. **왜 장치 모델이 검수 264장판인가?** 마지막 선형층만 8 epoch 학습해 외부 질의가 거의 같았고(±1~3개), 11-13 OTP2판이 삭제된 뒤 남은 후보였습니다. "더 좋다"는 증거는 없고 "해가 없다" 수준입니다.
7. **SOLIDER 파인튜닝은 효과가 있었나?** 원본 대비 +0.154(0.055~0.313)지만 한 사람이 사전 규칙을 깨서 "판단 불가"이고, 공개 자료만 쓴 D에서도 +0.130이 나와 우리 라벨의 몫은 보이지 않았습니다.
8. **E는 왜 장치에 올렸나, 기본이 아닌가?** 사전 규칙은 "더 좋지 않음"(옥상 −0.04)이고 추적 IDF1도 82.4 vs 83.0이라 기본 모델은 유지, 실내 근거리 4명 장면에서만 나아서(IDF1 51.1 → 61.2) 시험 선택지로만 추가했습니다.
9. **INT8에서는 어땠나?** RepVGG FT OTP2는 장치 INT8 .892/.834가 PC float .890/.840과 거의 같았습니다. 검수 264장 판은 코사인 변화 p95 0.154, E는 진단 코사인 0.982만 있고 장치 정확도는 없습니다.
10. **11-11 ViT-lite는 어떻게 학습했나?** 기록이 없습니다. 있는 것은 "선생 SOLIDER, 우리 실내"라는 모델뱅크 한 줄과 11-20 장치 채점뿐입니다.
