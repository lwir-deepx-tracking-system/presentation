# 윤관 발표 대본

같은 장에 선택 이유, 방법, 결과를 함께 묶었습니다. 세부 실험 조건은 notes_상세.md와 sources.md에 있습니다.

## 01 · 담당 역할 및 개발 범위

저는 학습을 중심으로 데이터 라벨을 정리하고 검출·자세 모델을 학습한 뒤 후보를 평가했습니다. 짐벌 제어와 장치 시험도 맡았습니다. 결과가 좋아진 항목뿐 아니라 기준을 통과하지 못한 후보도 확인해 장치 적용 여부를 판단했습니다.

## 02 · 열화상 탐지 모델 검증 비교

FLIR 검증에서 YOLOX 39.96%, YOLOv8 42.28%, YOLO26s 44.93%를 비교했습니다. 이 비교는 s급 후보 평가이지 m급 선택 근거를 직접 증명하지 않습니다. 후속 M1의 s/m 속도·정확도 비교는 뒤쪽 장치 파트 결과입니다. 뒤의 장치 비교와 같은 11월 6일 사후 측정에서는 FLIR 8편에서 s와 m의 사람 AP가 42.32%, 45.79%, NPU 호출 중앙값이 19.02ms와 27.12ms였습니다. 한 번의 측정이며 학습 이력이 달라 크기만의 효과나 m을 처음 선택한 이유로 사용할 수 없습니다.

## 03 · FLIR 데이터 기반 전이학습

COCO 가시광에서 FLIR 열화상으로 옮기면 영상의 밝기와 질감이 다르므로, 사전학습 가중치를 열화상으로 파인튜닝했습니다. FLIR 10,491장, 640 입력, batch 8, 최대 30 epoch, seed 202로 학습했습니다. AdamW 초기 학습률 0.0003, weight decay 0.0005, 3 epoch warmup, cosine schedule, BN 이동통계 고정을 사용했습니다.

## 04 · 학습 에폭 선정 및 소형 객체 개선

30 epoch는 비교에 쓴 최대 예산이지 최적 종료가 입증된 epoch가 아닙니다. 별도 YOLO26s FT 단일 실행(seed 101)의 15→30 epoch Primary-6 검증 mAP50–95는 40.4133%에서 41.3342%로 0.9209%p 증가했습니다. 이는 YOLO26m의 종료점 비교가 아닙니다. 그 뒤 YOLO26m 기준에서 각 12 epoch씩 여섯 소형 후보를 비교했습니다. 기준 Full FT 50.72%, 최고 실제 소형 데이터 seed303 후보 51.06%로 +0.34%p였습니다. NWD는 작은 상자에서 IoU 민감도를 줄이려는 거리 기반 손실 계열입니다. 이 후보 시험은 NWD 할당과 손실이 함께 바뀌었으므로 원인을 분리하지 못합니다. 32px 미만 AP 범위도 함께 제시했습니다.

## 05 · Full FT·LoRA 학습 로그 및 검증 성능

Full fine-tuning은 사전학습 가중치를 함께 갱신하고, LoRA는 기존 가중치를 고정한 뒤 작은 저랭크 행렬을 학습합니다. 열화상 적응에서 학습 방식과 자원 차이가 성능에 어떤 영향을 주는지 비교했습니다. 그림은 실제 YOLO26s 한 시드 실험이며 m급 최적 종료점을 증명하지 않습니다. LoRA 원 논문은 언어 모델을 다루므로 프로젝트 결과는 별도 실험입니다. 그래프의 상자 손실은 각 CSV의 train/box_loss이고, 검증 성능은 monitor_primary6/mAP50_95입니다. 같은 seed와 batch의 세 실행이며, 상자 손실만으로 전체 손실을 대표하지는 않습니다.

## 06 · 데이터 규모에 따른 검증 성능

YOLO26s, FLIR 6개 클래스, 30 epoch, seed202에서 네 데이터 규모를 측정했고 빈 점은 그 사이를 직선 보간했습니다. Full FT는 29.25, 33.69, 38.93, 41.09이고 LoRA는 27.60, 31.51, 36.51, 38.11 mAP50–95입니다. x축은 이미지 수, y축은 정확도입니다. 초반 구간의 기울기가 더 컸지만 업데이트 수가 데이터 규모와 함께 증가하므로 원인을 데이터 수만으로 분리할 수 없습니다. 약 4천 장은 후속 검증을 잡는 지점이며 일반적인 스케일 법칙이나 최적 데이터량을 입증하지 않습니다. Hestness et al.은 이론적 배경입니다.

## 07 · 학습 예산별 FT·LoRA 성능 비교

두 조건 모두 라벨 10%, FLIR 검증 1,144장입니다. 30 epoch 1회에서는 Full FT 34.22%, LoRA 32.61%로 FT가 1.61%p 높았습니다. 297 epoch·5,049 업데이트 조건에서는 FT 29.89%, LoRA 33.96%로 LoRA가 4.07%p 높았습니다. 학습 예산에 따라 순위가 바뀌었습니다. 장기 학습 값은 통합 기록 기반이며 원본 run 재대조가 필요합니다.

## 08 · YOLO 검출기 증류 실험

이것은 검출기 YOLO26m에서 YOLO26s로 간 증류 실험입니다. 큰 교사의 특징을 작은 학생에게 전달해 계산량은 줄이면서 성능을 보존할 수 있는지 봤습니다. 60 epoch, 같은 초기값과 배치 순서, 단일 시드였습니다. FLIR 사람 AP는 44.8575에서 44.2334로 낮아졌고 추적 개발 평가에서 FP는 321→295로 줄었지만 FN 526→535, IDSW 12→17로 늘었습니다. 전체적으로 개선됐다고 판단할 수 없어 채택하지 않았습니다. SOLIDER→RepVGG 외형 증류와 혼동하지 않습니다. 이 60에폭 비교는 FLIR 학습 이미지 4,196장과 seed 202를 사용했습니다. 실제 증류 실행 CSV의 train/dis_loss는 1에폭 8.77978에서 60에폭 1.45011입니다. 같은 실행의 평가 기록과 체크포인트를 대조했으며 손실의 감소가 사람 AP의 향상을 뜻하지는 않습니다.

## 09 · 자세 모델 학습 데이터 구성

COCO pose에서 시작해 OTP2 열화상, 가림 증강, 흑백 COCO, MOT17 순으로 학습해 근거리 E를 만들었습니다. E에서 기존 자료로 더 학습한 R0와 LLVIP-Pose를 추가한 R1을 비교했습니다. R1에서 사무실 가림 조각을 추가한 O와 같은 설정에서 조각만 제외한 대조 C로 나눴습니다. 실내 개발 녹화 2편에서 탐지율은 비슷했지만 중복 상자는 O 마지막 0.19개, C의 세 번째 epoch 체크포인트 0.07개였습니다. 이 조건을 참고해 C epoch2.pt, 즉 0부터 세어 3에폭 지점을 범용 F로 골랐습니다. F는 근거리 E를 대체한 확정 모델이 아니라 별도 선택지입니다.

## 10 · 탐지·자세 모델 학습 입출력 및 평가

탐지 학습에는 열화상 이미지와 클래스·상자 정답을 넣고, 모델이 상자 위치와 클래스 점수를 예측하도록 학습합니다. FLIR 사람 AP50–95 50.72%는 YOLO26m 기준입니다. 자세 모델은 이미지와 사람 상자, 17개 관절과 보임 상태를 정답으로 받아 상자와 관절 위치를 예측합니다. OTP2 관절 AP는 E 80.4에서 F 85.1로 바뀌었고, TMOT HOTA는 다른 추적 평가입니다. 학습 후 가중치를 저장하고 AP 및 FP·FN 등을 확인했습니다. 앞의 YOLO26s FT·LoRA 그래프는 실제 검증 곡선이며 YOLO26s의 원본 CSV 세 개는 확보했지만 이 페이지에 표시된 YOLO26m과 자세 모델 실험의 원본 loss 파일 위치는 확인하지 못했습니다. M1 640×480 UINT8은 추론 입력으로 학습 이미지와 구분합니다. 장치용 기본 자세 검출 파일은 상자·클래스 6출력이고, 관절을 내보내는 별도 파일은 관절 3출력이 추가된 9출력입니다. 이는 같은 학습 개념을 서로 다른 장치 출력 형태로 내보낸 것입니다.

## 11 · 가림 증강 및 자세 모델 학습 설정

가림은 실제 장면 배경 조각으로 확률 0.5, 프레임 밖 잘림도 확률 0.5로 적용했습니다. 크기 ±50%, 위치 이동 20%, 회전 5도, 좌우 뒤집기 0.5를 사용했습니다. 모자이크는 끄고 잘린 관절의 보임 표기가 부정확해질 수 있는 변형은 제외했습니다. R0/R1 학습은 AdamW, 배치 16을 4회 누적해 실효 64, 학습률 2e-4였습니다. 후속 미세조정은 1e-4를 썼고 batch32는 메모리 부족으로 사용하지 못했습니다.

## 12 · 공개 데이터셋 기반 자세 모델 평가

OTP2 test에서 관절 AP는 E 80.4, F 85.1이었습니다. TMOT val에서 HOTA는 19.5→32.8, 25–50px 사람 검출률은 7→41이었습니다. 데이터셋별 지표가 다르므로 같은 지표 안에서만 비교합니다. TMOT은 후속 보정에도 사용되어 독립 최종시험이 아닙니다.

## 13 · 자체 열화상 영상 라벨링

자체 카메라 녹화는 야외 15편 8,929장, 실내 7편입니다. 자동 후보를 그대로 정답으로 쓰기보다 직접 확인한 사람 상자와 ID, 관절을 정답으로 정했습니다. 이미지는 사용자가 제공한 실제 라벨링 화면입니다. 표시된 일부 선택 부위가 검수 필요 상태이고, 캡처 프레임이 학습에 포함됐는지는 확인되지 않았습니다.

## 14 · 원거리 배경 정제 및 관절 검수

원거리 자동 상자 8,049개를 제외하고 카메라 위치 두 곳의 빈 배경 띠를 정리해 프레임 밝기를 맞췄습니다. 직접 라벨한 사람 영역 4,835개는 원본 픽셀과 맞는지 확인했습니다. 신뢰도 0.5 이상의 잔여 후보가 1,806개에서 0개가 됐습니다. 실제 정제 전후 화면은 확보되지 않았습니다. 야외에서는 1,069명과 11,824개 관절 후보를 보고 불확실한 379점을 모름으로 표시했으며, 무작위 10% 재검의 누락률은 약 0.9%였습니다. 박스 기준 미달 193명은 박스만 썼습니다. 실내 282장에서는 135개 박스를 고치고 빠진 2명을 더했습니다. 보이는 관절 1,688점을 표시하고 재검 오류 4.6%를 수정했습니다. 가린 관절의 위치 손실은 제외했습니다.

## 15 · 자체·공개 데이터 혼합 학습

학습 예제는 자체 야외 1,114, 실내 846, 공개 OTP2 380, 회색조 COCO 1,270, LLVIP 264, MOT17 40이었습니다. 실내 282장에 3회 반복을 적용해 846개 예제가 됐고 공개 자료를 함께 써 공개 일반화 성능이 사라지는지 살폈습니다. 범용 F에서 입력 640, warmup 2, AdamW 1e-4, 8 epoch, batch8×누적8로 NF를 만들었습니다. NF와 FX 비교 동점은 사전 규칙으로 NF를 선택했습니다. 먼 사람 검출은 84.6→99.5, 실내는 47.5→52.5로 올랐지만 야외 32px 이상은 97.45→95.55로 내려갔습니다. 실내 오검출도 0.068→0.152/장으로 늘어 기준 미통과로 장치에 채택하지 않았습니다. TMOT HOTA와 IDF1은 올랐지만 다른 기준을 통과하지 못했고 영상 노출도 있어 참고값입니다.

## 16 · 검수 데이터 기반 자세 모델 평가

V7은 사람 검수 영상 264장, 5장 정정과 증강을 사용해 YOLO26m-pose를 24 epoch, 213 updates 학습했습니다. OTP2 934장에서 별도로 평가했습니다. 660개 머리 상자는 별도 라벨이며 COCO17 학습 target에 넣지 않았습니다. V8 증강 1 epoch 비교에서 중복 후보는 320→154, 20–32px 누락은 24→12로 줄었지만 20px 미만 누락은 88→104로 늘고 OTP2 자세 AP는 0.7306→0.7194로 낮아졌습니다. 여러 사전 기준을 함께 통과하지 못했습니다. 264장은 자체 카메라 테스트셋이라는 뜻이 아닙니다. 선행 F와 O에서는 100픽셀 미만에 전신 상자, 그 이상에 상체 상자가 나오는 정의 혼재도 발견했습니다. 이 문제는 V7·V8의 평가 수치 자체와 구분해야 하며, 상자 크기 변동과 조준점의 원인으로 후속 점검했습니다.

## 17 · 외형 모델 증류: SOLIDER → RepVGG

외형 모델에서는 사람 이미지로 사전학습한 SOLIDER의 특징을 RepVGG 학생으로 옮기는 증류를 시험했습니다. 교사 특징 768차원, 학생 출력 128차원입니다. 교사는 학습에 쓰고 장치에는 작은 INT8 학생을 올리는 구성이었습니다. 선택 배경으로 열화상 신원 라벨의 확보 부담과 M1 연산 자원 한계를 고려했지만, 당시 증류를 결정한 직접 문서는 확인하지 못했습니다. 이전 PC 종합 평가에서는 교사가 0.738에서 0.773으로 개선됐지만 증류 학생은 0.660으로 기존 학생 0.694보다 낮았습니다. 768대 128 차원 차이가 원인이라는 해석은 가설입니다. SOLIDER 논문과 cross-architecture distillation은 원리 참고로 추가했습니다. 외형 모델의 입력은 사람 이미지 crop과 신원 정보이고, RepVGG 학생은 재연결 비교에 사용하는 128차원 특징을 출력합니다. 해당 증류 실행의 epoch별 원본 손실 로그는 확인되지 않았습니다.

## 18 · 외형 모델 추가 학습 및 평가

OTP2 시험 신원 60명에서 이전 RepVGG 몸 상자 Rank-1은 72%에서 89%로, 잘림은 18%에서 27%로, 가림은 65%에서 84%로 바뀌었습니다. 이는 PC float 외형 검색입니다. 11월 17일 별도 실험에서는 검수 260장, 672 crop으로 몸통은 고정하고 마지막 projection을 학습했습니다. TMOT과 CAMEL 결과가 엇갈렸습니다. 교사를 적응시킨 cosine 이동은 0.001007로 기준 0.003보다 낮았고, direct/original-teacher/adapted-teacher 3 seed 비교에서도 추가 이득이 확인되지 않았습니다. 이는 이전 OTP2 결과와 합산하거나 직접 비교할 수 없습니다. 별도의 직접 학습 A, 원교사 증류 B, 적응교사 증류 C는 3시드씩 비교했습니다. CAMEL 218개 질의에서 A는 200·200·200, B는 201·201·200, C는 201·201·201개였습니다. TMOT에서는 세 조건 모두 시드마다 386/432였고 사전 유지력 기준을 통과하지 못했습니다. 이 평가는 과거 실험에 사용된 자료이며 독립적인 새 카메라 검증이 아닙니다. 이전 OTP2 직접 추가 학습은 학습 200신원·3,563개 crop, batch-hard triplet 3,000 step을 사용했습니다. 이는 별도의 11월 17일 검수 데이터 직접 학습과 구분합니다.

## 19 · 가림 상황의 위치 예측: GRU·Mamba

사람이 보일 때 최근 최대 20프레임의 상자, 속도와 관절 특징을 기록합니다. 가려지면 먼저 카메라 움직임을 보정한 Kalman 경로를 만들고 GRU가 중심과 크기를 보정합니다. 이 예측은 최대 15프레임이며 충분한 관측이 없으면 Kalman 경로를 씁니다. 외형으로 ID를 재식별하거나 보이는 상자 크기를 필터링하는 기능과는 다릅니다. 서버 구현은 NumPy 순전파입니다. 지도 목표는 정답 GT 상자에서 사람 키별 변환표를 거쳐 만든 머리부터 골반까지의 몸 상자입니다. 화면 경계에 잘린 GT는 목표 계산에서 제외했습니다. 관절이 없는 큰 사람은 실제 검출기가 전신 상자를 내는 경우가 있어, 변환 목표와 상자 정의가 어긋나는 문제는 남았습니다. 입력은 프레임당 68차원으로, 상자와 속도 등 16값, 17개 관절의 상대 좌표·보임 51값, 유실 단계 1값입니다. 새 GRU는 화면 가장자리 4값을 고정하고 처음부터 30에폭 학습했으며 val-A로 29에폭을 골랐습니다. Mamba 역시 위치 기억 대조 모델로 관절·상자 시계열을 사용합니다. 해당 실행의 epoch별 원본 손실 로그는 확인하지 못했습니다.

## 20 · GRU·Kalman 위치 예측 및 ID 비교

자체 TEST 14편, 유실 238건에서 Kalman 위치 오차는 0.110, 이전 GRU 0.336, 수정 GRU 0.122였습니다. 관절이 없는 일부 상황에 Kalman을 적용하는 예외 규칙은 0.118이지만 별도 재학습 결과가 아닙니다. 반면 한 장치 녹화 seq_018에서는 IDF1이 Kalman 71.81, 새 GRU 75.36이었고 ID 전환은 17회에서 15회로 줄었습니다. 서로 다른 영상과 지표입니다. Mamba는 같은 위치 예측 평가에서 0.361에서 0.127로 좋아졌지만 Kalman보다 오차가 컸습니다. 자체 시험 영상을 분석에 사용했으므로 독립 최종 검증은 아닙니다.

## 21 · 추적 박스 크기 안정화

짐벌이 보는 상자가 흔들려 조준점이 튀는 문제를 줄이기 위해 박스 크기 필터와 상체 기준 통일을 시험했습니다. 기존 추적기, 크기 필터, 상체 통일 후보에서 프레임별 상자 높이 변화 상위 1%는 0.071, 0.054, 0.043이었습니다. 검출 모델 전환 19회에서도 변화는 0.051, 0.030, 0.015였습니다. 상체 통일은 수치만 낮았지만 다른 조준 떨림 기준을 통과하지 못해 적용하지 않았습니다. 전체 좌표 1€는 조준 떨림이 20% 늘었고 두 박스 보정 GRU도 채택되지 않았습니다. 실제 적용은 크기 필터입니다. 영상은 정답 없는 반복 시험이라 약한 근거입니다.

## 22 · FastTrackTr 학습 구성 및 평가

FastTrackTr은 학습 때 DanceTrack 36편의 grayscale 640×480 영상을 사용했고 RT-DETR ResNet18 COCO 가중치에서 시작했습니다. 이후 DanceTrack 흑백 학습에서 TMOT 열화상 24편과 DanceTrack 일부를 섞어 세 epoch 적응한 실험이 별도로 있습니다. 모델은 현 프레임과 과거 특징을 보고 300개 질의로 사람 상자와 ID 단어를 출력하며, 서버가 이 ID 단어를 연결에 사용합니다. 이 구조로 탐지와 시간 정보 연결을 함께 시험했습니다. 후속 3 epoch 실험에서 TMOT 6편 평균 IDF1은 15.3에서 27.1로 올랐고 11개 저장 녹화 중 9개 개선, 2개 악화였습니다. 실내 두 녹화는 나빠졌고 기준 추적보다 낮아 시험용으로 유지했습니다. 기록 로그는 녹화별 IDF1과 재현율이며, epoch loss 원본은 이번 근거에서 찾지 못했습니다. DXNN 보정용 이미지 개수와 DanceTrack/TMOT 학습 분량은 서로 다른 단계입니다.

## 23 · ONNX 내보내기 및 INT8 변환

학습 PyTorch 가중치를 ONNX로 내보내고 보정 입력으로 DX-COM 컴파일을 거쳐 DXNN을 만듭니다. 공개 변환 예시는 opset 17, PyTorch와 ONNX Runtime 출력을 대조합니다. FLIR 검출기 메타데이터는 보정 8장, EMA, CPU를 기록합니다. 실내 FT는 FLIR과 실내 각 8장, 자세 모델은 자체자료 97장입니다. 보정은 재학습이 아닙니다. 실제 scale, zero point와 이미지 원본은 없습니다. 검출기는 640×480 UINT8 3채널 입력, 여섯 FLOAT32 출력 뒤 서버가 sigmoid와 클래스별 NMS를 적용합니다. compile metadata는 실행 증거가 아니며 동일 가중치 FP32와 INT8의 정확도 비교가 남아 있습니다.

## 24 · 외형·FastTrackTr 모델 변환

외형 모델의 공개 OTP2 변환 예시는 RepVGG 추론 구조를 합쳐 ONNX opset 17로 내보내고 256 crop으로 EMA 보정합니다. 입력 128×64×3, 출력 128차원입니다. 최신 직접 학습 모델과 같은 빌드인지 확인되지 않았습니다. FastTrackTr은 NPU 연산 제약 때문에 AE, B0, B1 세 그래프로 분리합니다. INFO에는 보정 17장, 공개 코드에는 앞 16장이 나와 있고 차이는 아직 해소되지 않았습니다.

## 25 · M1 병렬 처리 및 모델 성능

11월 3일 저장 FLIR 영상에서 검출을 NPU 0과 1에 교대로 투입하고 CPU 광류, NPU 2의 외형 추출을 겹쳤습니다. 동등 계산 처리량은 46.5에서 72.5 FPS로 늘었고 출력 바이트는 같았습니다. 후속 M1 INT8 한 번의 비교에서 사람 AP는 s 42.32%, m 45.79%, 호출 중앙값은 19.02ms와 27.12ms였습니다. 두 모델의 학습 이력도 달라 크기만의 효과로 단정할 수 없습니다. 이 숫자는 입력부터 화면까지 전체 지연과 다릅니다.

## 26 · M1 운영 화면

실제 TMOT 저장 영상을 재생하는 운영 화면을 넣었습니다. 박스와 ID, 프레임 진행과 일부 통계를 볼 수 있습니다. 화면은 저장 녹화 기반 재생이며 실시간 짐벌 동시 추종이나 독립 정확도 평가를 입증하지 않습니다.

## 27 · 짐벌 제어 및 실제 장치 응답

검출·추적에서 선택한 사람 중심과 화면 중심의 차이를 제어 입력으로 써 팬·틸트 명령을 만들었습니다. 작은 오차에서 반복 반전을 줄이기 위해 불감대를 0.04에서 0.06으로 조정했습니다. 세로 적분 후보는 8회 반전해 Ki를 0으로 두었고, Kd 5, 6, 7은 반복 오차 범위여서 6을 골랐으며 Kp는 30을 유지했습니다. 실제 짐벌과 가상 표적으로 반전은 줄었지만 수평 뒤처짐은 14.3px에서 18.6px로 커졌습니다. PID 논문은 일반 원리 참고이며 구체 설정은 프로젝트 시험 근거입니다. 그래프는 2026년 11월 10일 실제 짐벌과 카메라에 가상 표적을 입력한 stage7의 수직 등속 시험으로, 불감대 0.04와 0.06 각각 한 번의 frames.csv에서 run 구간만 뽑았습니다. ey 정규화 오차에 240을 곱해 픽셀로 표시했고 2.5초에 가상 표적이 정지합니다. 조건당 99프레임과 100프레임이며, 정지 후 명령 방향 반전은 4회에서 1회로 줄었습니다. 가로 뒤처짐 14.3에서 18.6픽셀은 별도 수평 시험입니다. 실제 사람 추종의 종단 검증은 아닙니다.

## 28 · 가림 전후 ID 유지 비교

왼쪽은 동일한 가림 사건의 열화상 입력, 오른쪽은 기준 tracker와 후보를 나란히 시각화한 비교입니다. 한 개발 영상의 사례에서 기준은 재등장 뒤 ID가 바뀌고 후보는 이어졌습니다. 이 영상은 후보 구성 선택에 사용됐으므로 독립 테스트나 모든 가림 상황에 대한 보장은 아닙니다.

## 29 · 주요 성과 및 후속 검증

내 담당은 열화상 검출과 자세 학습, 외형·위치 기억 비교, 모델을 장치에 올리는 과정, 짐벌 제어입니다. 결과가 좋아진 부분과 기준을 통과하지 못해 채택하지 않은 부분을 함께 봐 주시면 됩니다. 아직 독립된 실카메라 ReID, 동일 조건 FP32와 INT8, 교사와 학생의 같은 M1 비교, 짐벌 반복 및 전체 종단 지연이 남아 있습니다.
