INT8 보정은 검수 264장을 왼쪽·오른쪽으로 잘라 만든 528조각으로 했고, DX-COM 결과는 전부 NPU에서 돌아 CPU 부분이 없습니다. 두 출력은 오른쪽 타일 좌표에 256 px를 더하고, 상자 중심이 가로 320 px 왼쪽이면 왼쪽 타일 것, 오른쪽이면 오른쪽 타일 것만 남긴 뒤 한 번의 NMS로 합칩니다. 학습에 쓴 264장 진단에서 맞힌 사람은 445명 대 457명으로 비슷했지만 독립 시험은 아니고, 운영 중인 현장 650장 E10 분할판의 전체 화면 대비 정확도는 따로 재지 않았습니다.
