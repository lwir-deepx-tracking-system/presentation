## 추가 3 epoch과 시간 손실

상체 E10에서 650장으로 3 epoch, 126회 갱신한 두 갈래다. 하나는 일반 추가 학습 대조, 하나는 두 프레임의 상자 이동량 차이를 줄이는 시간 손실을 넣었다. 수동 박스 29쌍은 중심·폭·높이 변화, 관절로 움직임을 확인한 101쌍은 중심 변화만 사용했다.

| OTP2 934장 검증 | 시작 E10 | 3 epoch 대조 | 3 epoch 시간 손실 |
| --- | ---: | ---: | ---: |
| 박스 AP50–95 | 46.28% | 40.23% | 40.21% |
| 관절 AP50–95 | 78.35% | 74.58% | 74.58% |

두 추가 학습의 AP가 비슷하게 떨어졌으므로 시간 손실만이 하락의 원인이라고 결론낼 수 없다. 학습에 노출된 129쌍의 중심 이동 오차 p95는 11.43 → 11.15 → 11.14px이고, 시간 손실과 대조의 차이는 약 0.013px이다. **독립 영상에서 흔들림 개선은 미확인**, 기존 E10보다 우월하다는 근거가 없어 운영 교체를 보류한 시험이다.

로컬 원본: 위 학습 폴더의 `temporal_consistency_20261119_v1/e10_controlled_ft_v1/RESULT_KO.md`, `VALIDATION.json`. 공개 모델뱅크 문서의 E10+3은 시험 모델로 등록됐다는 기록이며, 등록을 최종 채택으로 해석하지 않는다.

## 화면에서 상체·전신 표시

상체 박스와 관절을 이용해 전신 범위를 **표시용**으로 계산한다. 발목이 유효하면 발목을 우선하고, 없으면 무릎과 선 사람의 비율을 차례로 사용한다. 전신 표시로 바꿔도 ID 매칭, 추적 채점과 짐벌 조준은 기존 상체 추적 좌표를 쓴다.

E10의 `seq_003` 56장·190개 대응 상자에서 전신 정답과의 중앙 IoU는 0.427 → 0.744, 하단 중앙 절대 오차는 60.4 → 4.8px이었다. **190개 모두 발목 관측 경로**이므로 무릎이나 하체 가림 추정의 정확도는 평가되지 않았다. 상체 박스와 전신 정답의 크기 정의가 다르므로 이 수치를 검출 모델 자체의 AP 개선으로 읽지 않는다.

발표 이미지는 로컬 `D:/lig_ft_20261116/eval/LWIR650_E10_gui_m1_20261119_v1/BOARD_POSE_UPPER_REPLAY.jpg`와 `BOARD_POSE_FULL_REPLAY.jpg`다. 장치의 실제 열화상 녹화 재생 JPEG이며 서로 다른 프레임이어서 ID·정량 성능 직접 비교가 아니다. 이미지 프레임 번호를 확인할 별도 JPEG 보고 파일은 찾지 못했다. 같은 폴더의 `UPPER_FULL_SEQ002_228.jpg`는 두 모델을 비교한 다른 그림이므로 전신 투영의 동일 모델 사례로 사용하지 않았다.

주의: 최신 공개 모델뱅크에는 박스 표시 **문서**가 있지만, 문서가 참조하는 `src/detect/pose_full_box.py`와 `pose_duplicate.py`는 기준 커밋의 공개 트리에서 확인되지 않았다. 장치에서 확인한 구현과 GitHub에서 내려받을 수 있는 코드를 동일시하지 않는다.

## NPU 0·1 동시 타일과 지연

입력 640×480을 폭 384px 타일 두 개로 나누고 128px 겹친다. NPU 0과 1이 같은 프레임을 동시에 처리하고 원래 프레임 좌표로 옮겨 병합·사람 NMS를 수행한다. [타일 구현](https://github.com/lwir-deepx-tracking-system/model-bank/blob/6ee8022c82d741b92631aa2561fdd89a26b8b84e/tracking_server/src/detect/dual_tile.py). 장치 모델·전처리 준비가 된 경우의 시험 선택지다.

11월 19일 실카메라 약 30 FPS, 각 65초 측정의 **서버 수신→추적 완료 p95**는 프레임 교대 40.47ms(최근 표본 1,800개, 큐 버림 0), 동시 분할 25.71ms(1,799개, 큐 버림 1)였다. 처리 순서 오류는 둘 다 0이었다. 이 구간에서 33ms 지연 목표는 통과했지만 무손실은 아니다. 브라우저 표시와 짐벌 물리 응답은 측정 구간 밖이다. 녹화 재생의 310장·32.47ms는 별도 시험이며 위 실카메라 수치에 합치지 않는다.
