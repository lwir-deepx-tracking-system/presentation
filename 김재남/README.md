총 목표 시간은 4분 30초다. 각 장 원고와 검증 범위는 speaker-notes.html / speaker-notes.md에서 확인한다. 실제 낭독 속도로 최종 조정한다.

index.html은 오프라인 HTML이다. presentation.pdf는 1280×720 기준으로 슬라이드별 한 페이지인 4페이지 PDF다. 공통 slides.css와 로컬 Pretendard·공식 로고를 포함한다. slide-05.png, slide-08.png, slide-11.png, slide-12.png는 각 장 미리보기이고 overview.png는 모음이다. assets의 SVG는 편집 가능한 독립 구성도다.

코드 근거는 sources.md, 렌더링 검증 결과는 validation.json에 기록했다. PC 화면은 역할·통신 계약 도식으로 표현했다. 실제 GUI 동기화와 NPU 추론·성능은 이번 제작에서 미검증이다. 작업 경로는 ~/workspace/presentation/pipeline-presentation-v4다.
