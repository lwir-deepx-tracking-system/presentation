먼저 익힐 구조

처음에는 아래 흐름과 굵은 문장부터 이해하세요. 질문마다 짧은 답변 아래에 이해 메모가 있고, 그다음에 꼬리질문이 있습니다.

PC는 보고 선택한다 → 서버는 해석한다 → 보드는 추적·제어한다 → 짐벌이 움직인다.

GUI 화면을 보는 PC와, HTTP 서버·추론·짐벌 브리지가 있는 Orange Pi의 역할을 구분하세요.

GUI를 설명하는 다섯 문장
  1. HTTP는 요청·응답 방식, JSON은 상태 데이터 형식, MJPEG는 JPEG를 연속 전달하는 영상 형식입니다.
  2. 영상은 GET /stream, 사람 목록·상태는 GET /gimbal/people 같은 경로를 사용합니다.
  3. 선택·이동·정지는 POST /gimbal/click, /gimbal/move, /gimbal/stop 같은 요청으로 전달됩니다.
  4. Python 서버는 추적 상태를 관리하며 C++ 짐벌 브리지와 파이프로 통신합니다. 브리지는 시리얼 장치 제어로 연결됩니다.
  5. HTTP 요청 성공 ≠ 물리 동작 완료. 응답·선택 상태·장치 반응을 구분합니다.

GitHub는 “어떤 코드인가”, Docker는 “어떤 환경인가”.

같은 결과에는 모델·설정·입력·장비도 필요합니다.

WSL Runtime 소스→ bind mount →개발 컨테이너→CMake·Ninja·CTest

현재 확인한 lwir-dev build는 설정·빌드를, lwir-dev test는 시험을 실행합니다. 컨테이너 빌드 성공이 보드 카메라·NPU·짐벌 통합 성공을 뜻하지 않습니다. 실제 보드에서 서버가 컨테이너로 배포됐는지는 이번 확인 범위 밖입니다.

이 순서로 연습하세요

  1. 구조부터. 영상·상태·조작을 나누고, 서버에서 브리지·시리얼까지 연결해 말합니다.
  2. 우선 질문. “PC·보드 역할 / 통신 / PD / 표적 소실 / 보드 공유 / AI 활용 / 일정 / 느낀 점”에 짧게 답합니다.
  3. 꼬리질문. “직접 확인했나?”, “실제로 그 옵션인가?”, “무슨 조건의 결과인가?”를 이어서 묻습니다.
  4. 자기 경험 두 개. 설계와 다르게 생성된 AI 코드의 사례 하나와, 실제 장비 사용을 조율한 사례 하나를 기억해 둡니다.

기존 코드 확인 기록과 이번 답변의 범위

이 페이지의 기존 정리에서 2026-11-26 로컬 model-bank 7d747df, Runtime 916bca1과 발표 대본을 확인한 기록입니다. 이번 개정은 대화에서 사용자가 설명한 경험과 답변을 반영했으며 코드를 다시 검증하지 않았습니다. 로컬 코드 스냅샷과 실제 보드에 배포된 버전이 같다는 보장은 하지 않습니다.

  • page_handler.py: HTTP/1.1, /stream, /gimbal/people, 선택·이동·정지, /perf, /healthz.
  • stream_sender.py: multipart JPEG 영상 전송.
  • 03_gimbal_control.js: 클릭·수동 방향·입력 해제와 정지 요청.
  • gimbal_link.py: C++ 브리지 프로세스 생성, stdin/stdout 통신. 최종 브리지 버전과 활성 옵션은 미조회.
  • Runtime 개발 Dockerfile: CMake·Ninja·GStreamer·OpenCV 등. WSL 로컬 ~/.local/bin/lwir-dev의 소스·빌드 bind mount와 configure/build/test 경로도 읽었습니다. 이 래퍼의 PC 개발 설정은 카메라 OFF·DX 앱 ON입니다.
  • NASA: Product Realization: Verification과 Validation의 구분. NASA: Fundamentals: 요구·설계·통합·검증의 관계. V모델 대응표는 우리 자료를 정리한 예시이며 당시 정식 적용을 입증하는 문서가 아닙니다.
  • Docker 공식: 이미지와 컨테이너: 환경 패키지와 실행의 구분. 코드 버전 관리와 실장비 재현성까지 대체하지 않습니다.

확인하지 않은 것: 실제 보드의 실행 명령·현재 GUI 옵션·HTTP 전체 자동 시험 통과 수·모든 팀원의 동일 이미지 사용·개인의 갈등이나 일정 사건. 해당 부분은 확정 답변 대신 확인 범위를 표시했습니다.
