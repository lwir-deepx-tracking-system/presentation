## 반영한 팀원 변경

- ByteTrack·OC-SORT·BoT-SORT를 공통 C++ Tracker 인터페이스로 구성.
- GUI 선택 번호를 TCP로 요청하고 Runtime 카탈로그 설정으로 생성.
- 다음 프레임 경계에서 교체, Accepted/Completed 구분, 생성 실패 시 기존 추적기 유지.
- 기본 추천 BoT-SORT, ID 변경·재현율에 강점이 있는 OC-SORT도 유지.

알고리즘 내부·파라미터 튜닝·성능 비교는 정하건 파트에서 설명한다. 윤오름 파트는 시스템·PC 통신·표시·계측·제어 연결과 변경 상태 확인에 집중한다.

## 최종 반영 항목

- 실제 GUI 캡처, 선택한 추적기와 설정, 교체 후 표적 ID 처리.
- 실제 영상 코덱과 제어값·단축키. 다른 구현의 공개 기본값을 그대로 적용하지 않는다.
- 같은 운용 설정의 FPS·표시 지연·짐벌 반응 계측. 팀원 제공 기능 자료와 실제 현장 시험은 구분한다.
- 표지 하드웨어 사진: B안에 assets/hardware-photo.jpg 추가 후 B·개인 자료 순서대로 재생성.

## 재생성

공통 장·제어 도식은 최신 work/B에서 가져오며 디자인도 공유한다. 개인 담당 통신·GUI 변경·검증 장은 이 폴더의 build.py에서 관리한다.

```powershell
python work/B/build.py
python 윤오름/build.py
python 윤오름/render-presentation.py
```

PDF 9페이지·16:9, 폰트·이미지·잘림·키보드 이동을 검사한다. 현재 목표 시간은 약 7분 5초이며 실제 낭독 시간은 미측정이다. 전체 20분 발표의 담당 부분용 자료다.

[이전 웹 GUI·제어 비교 분석](model-bank-GUI-제어-비교분석.md)은 연구 기록으로 보존한다. 과거 Qt 모의 화면과 웹 합성 화면 에셋도 보관만 하며 발표에는 넣지 않는다.
