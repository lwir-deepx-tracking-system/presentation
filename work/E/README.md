# 발표자 노트 입력본

- **[E_발표자노트_피드백반영.pptx](E_발표자노트_피드백반영.pptx)**: 최신피드백13개페이지와MD형식변경을반영한본문35장노트사본.
- E.pptx: 사용자가 제공한 원본. 수정하지 않았다.
- [이 폴더의 대본 MD](speaker-notes.md) / [D 수정 원본](../D/work-pdf-20261125/speaker-notes.md): 동일한 최신 대본이며 낭독 문장과 선택 전환만 노트에 반영했다.
- [검증 결과](notes-validation.json): 본문35장 내용 대조·노트 일치·슬라이드50장과 기존 자산 보존 확인.

부록36~50장과 기존 노트는 유지했다. 모든 슬라이드XML과 변경 대상이 아닌 패키지 파일은 원본과 바이트 단위로 동일하다. 따라서 슬라이드의 사진·도형·애니메이션은 다시 생성하지 않았다. PowerPoint앱에서 직접 열어보는 확인은 수행하지 않았다.

대본을 바꾸면 D의MD를 수정하고 `build_notes.py`로 매핑을 갱신한 뒤 `python work/E/add_speaker_notes.py --output E_발표자노트_피드백반영.pptx`를 실행한다. 원본과 최신PDF의 장 순서가 일치하는지 검사한 후 사본에 입력한다. 해당사본이열려있으면새출력파일명을지정한다.
