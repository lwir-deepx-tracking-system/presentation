# 발표자 노트 입력본

- **[E_발표자노트_피드백반영.pptx](E_발표자노트_피드백반영.pptx)**: 이 폴더의 현재 MD 대본 전체를 반영한 본문 35장 노트 사본.
- E.pptx: 사용자가 제공한 원본. 수정하지 않았다.
- [이 폴더의 대본 MD](speaker-notes.md): 발표자 노트의 기준 원문. D의 이전 초안과 별도로 관리하며, 낭독 문장과 선택 전환만 노트에 반영한다.
- [검증 결과](notes-validation.json): 본문35장 내용 대조·노트 일치·슬라이드50장과 기존 자산 보존 확인.

부록36~50장과 기존 노트는 유지했다. 모든 슬라이드XML과 변경 대상이 아닌 패키지 파일은 원본과 바이트 단위로 동일하다. 따라서 슬라이드의 사진·도형·애니메이션은 다시 생성하지 않았다. PowerPoint앱에서 직접 열어보는 확인은 수행하지 않았다.

대본을 바꾸면 E의 `speaker-notes.md`를 저장하고 `python work/E/add_speaker_notes.py --output E_발표자노트_피드백반영.pptx`를 실행한다. MD를 직접 읽으므로 D의 매핑을 갱신할 필요가 없다. 원본과 기준 PDF의 장 순서가 일치하는지 검사한 후 사본에 입력한다. 해당 사본이 열려 있으면 새 출력 파일명을 지정한다.
