처음에는 화면과 말할 내용을 함께 본다. 다음 연습에서는 큐시트의 세 단서만 보고 설명하고, 대표 수치는 화면을 보며 읽는다. 실제 시간을 잰 뒤 문장이 막히거나 설명이 늘어나는 장만 조정한다.

대본은 현재 PDF의 순서·사진·표에 맞췄다. 계획1,000장과학습650장, 외형 모델명·호출시간, 추적기 평가환경 차이와KeepID 비교기준은 확인 메모에 따로 남겼다. 각 메모를 발표 중 낭독할 필요는 없다. 내용이 바뀌면 `script_data.py`를 수정하고 다음 명령으로 다시 생성한다.

```powershell
python work/D/practice-15min/build.py
```

읽기용·MD·큐시트·script.json을 생성한다. 인쇄PDF와브라우저검증은 `render.py`로 갱신한다. 원본PDF·근거는 이 폴더에 동결했으며 Downloads를 자동 재조회하지 않는다. C·final·팀원 원본에 자동 동기화하지 않는다.
