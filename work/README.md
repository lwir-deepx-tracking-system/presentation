# 발표자료 작업 폴더

팀원 원본을 보존하면서 전체 발표를 정리하는 작업본입니다.

**수정·인계 시 필독: [디자인·편집 기준](DESIGN.md).** 제목은 `운용 화면`처럼 짧은 명사형 한 줄로 쓰고, 작은 분류명과 큰 제목을 중복 표시하지 않습니다. 앞으로 만드는 안에도 같은 기준을 적용합니다.

**새로 만들기 전에는 [재구성 인계 문서](HANDOFF.md)를 먼저 확인합니다.** 최근 사용자 요구사항, 표지·팀장 표기의 차이, 역할 요약, 그래프 기준, GUI 논의의 보류 상태와 남은 입력을 한곳에 정리했습니다.
