# 추적 알고리즘 슬라이드 근거 수치

모든 수치는 실제 실행 로그에서 나온 값입니다. 원본 문서는 팀 공유 폴더의 같은 이름 문서입니다.

## 공통 조건
- 검출: YOLO26s (DEEPX NPU), 같은 검출 결과로 추적기만 바꿔 비교
- 데이터: LWIR 실데이터 seq_001~018, 정답 직접 라벨링 (MOT 10열)
- 평가: TrackEval (HOTA, CLEAR, Identity). 합계는 18개 시퀀스 개수를 더해 다시 계산
- 카메라 움직임 보정(CMC): 사용하지 않음 (고정 카메라 녹화)

## 비교할 때 주의
- 01·04쪽의 "531"과 "66.7%"는 PC 재실행 결과, "2,964"와 "49.6%"는 Orange Pi 결과입니다. 검출은 같고, 기준 설정에서 두 환경의 IDSW가 784 vs 775로 맞음을 확인했습니다.
- HOTA는 03쪽은 시퀀스 평균, 파라미터·옵션 표는 TrackEval 합산(COMBINED)이라 서로 직접 비교하지 않습니다.
- 03쪽 원인 열은 측정값이 아니라 구조와 장면별 결과로 본 분석입니다.
