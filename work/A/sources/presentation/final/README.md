# 최종 취합본

각 담당자의 완성 자료를 발표 순서대로 합치는 폴더입니다. 초기 구조에는 최종 HTML·PDF가 아직 없습니다.

## 취합 시 넣을 파일

- `index.html`: 전체 발표 HTML
- `styles.css`: 취합본 스타일
- `assets/`: 최종본에 필요한 이미지·폰트 등
- `presentation.pdf`: 최종 PDF
- `notes.md`: 전체 발표 대본
- 데모 영상이 별도 공유되어 있으면 재생 위치·파일명·버전 기록

## 확인 항목

- 1920×1080, 16:9와 공통 디자인 유지
- 순서·페이지 번호·용어·단위·출처 통일
- 한 슬라이드당 PDF 한 페이지
- 이미지·폰트·영상 경로 확인
- 데모 포함 20분 이내로 발표 시간 확인

개인 작업 자료는 본인 폴더에 올리고, 이 폴더는 최종 취합 시 갱신합니다.
