# 윤관 발표자료 검토 메모

## 발표에서 확인되는 기여

열화상 데이터·라벨 검수, 검출·자세 및 외형 모델의 학습과 비교, 추적 위치 예측, M1 변환과 실행 확인, 짐벌 제어 시험을 하나의 흐름으로 정리했다. 실제 라벨 편집 화면은 작업 중 캡처이며, 선택된 부위는 검수 필요 상태다.

## 보완한 부분

- **사람 박스 생성:** 실제 라벨 편집 화면과 별도의 개념도를 나란히 두고, 관절 기반 템플릿으로 머리~골반 학습 상자를 만드는 이유와 관절 부족 시 보완 규칙을 명시했다. 11월 15일 전처리 보완이 이전 F/O 가중치에 소급되지 않는 점도 구분했다.

- **학습 계보:** 자세 모델의 근거리 E → R0/R1 → 가림 O/대조 C 분기를 그렸다. F는 C의 세 번째 epoch 체크포인트이며, E를 확정적으로 대체한 모델이 아니라 별도 선택지다. 선정에 쓴 실내 개발 녹화는 2편이다.
- **검출기 증류:** 실제 60 epoch FT·KD CSV를 평가 체크포인트와 대조하고 증류 손실 곡선을 추가했다. 손실은 줄었지만 검증 사람 AP는 44.8575% → 44.2334%였다. 학습 손실과 성능은 다른 지표다.
- **외형 모델:** 직접 학습·원교사·적응교사 증류의 3시드 CAMEL 결과를 실측 점으로 표시했다. 과거 사용된 평가셋이므로 새 카메라의 독립 검증으로 주장하지 않는다.
- **위치 기억:** 실제 모델 입력과 Kalman 보정 출력, GT에서 몸 상자 목표를 만드는 과정을 표시했다. GRU의 위치 오차는 같은 TEST에서 Kalman보다 작지 않았고, 한 영상의 IDF1 개선은 별도 결과다.
- **짐벌:** 실제 카메라·짐벌에 가상 표적을 사용한 시험의 수직 오차를 `frames.csv`에서 그렸다. 각 불감대는 1회씩이며, 실제 사람의 종단 추종 결과가 아니다.
- **학습 예산:** 30 epoch는 비교 예산이며 최적 종료점은 아니다. 확인된 YOLO26s 단일 FT 로그에서 15→30 epoch 검증 mAP 변화는 +0.9209%p다. YOLO26m의 수렴 근거로 사용하지 않는다.

## 평가자가 추가로 확인할 자료

1. **YOLO26m 선정 당시 기록:** 동일 입력·정밀도·데이터에서의 후보별 정확도, 작은 사람 성능, M1 호출 시간과 메모리. 현재 s/m 장치 비교는 선정 후 측정이며 학습 이력도 다르다.
2. **독립 현장 검증:** 학습·모델 선택에 쓰지 않은 별도 촬영분의 사람 박스·ID 정답, 가림 전후 IDF1·IDSW와 오탐·누락. 기존 외형 및 위치 기억의 일부 시험은 개발에 노출됐다.
3. **원본 학습 로그:** YOLO26m 자세·외형 증류·위치 GRU/Mamba·FastTrackTr의 해당 실행 epoch별 손실과 검증 기록, 설정 및 checkpoint 대응 관계. 찾은 YOLO26s FT·LoRA와 60 epoch FT·KD 로그는 폴더에 첨부했다.
4. **양자화 전후 성능:** 같은 가중치·입력·후처리 조건의 FP32와 M1 INT8 정확도 및 반복 지연. 컴파일이나 실행 성공만으로 정확도가 유지됐다고 볼 수 없다.
5. **실물 및 반복 시험:** 짐벌 본체·카메라가 함께 보이는 실제 장치 사진, 동일 시각의 영상·제어 명령·각도 기록, 조건별 반복 시험. 제공·보관된 범위에서 짐벌 실물 사진은 찾지 못했다.

논문은 선택 원리의 참고문헌이며, 프로젝트에서 당시 직접 참고했다는 확인이 없으면 그렇게 주장하지 않는다. 상세 출처와 평가 조건은 [sources.md](sources.md), 모델별 입력과 로그는 [보충 설명](학습_입출력_로그.md)에 있다.
