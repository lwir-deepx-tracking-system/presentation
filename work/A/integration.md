# 발표용 재편집과 최종 인계

2026-11-18. 본문 14장 + 예비자료 18장. 목표 17분 발표 + 3분 데모 = 20분. 실제 낭독 시간은 미측정.

## 편집 결정

- 작업 목록 대신 운용 장면 → 팀 → 시스템 → 찾기 → ID 유지 → 반응 → GUI → 데모 → 검증 → 마무리 순서.
- 본문은 큰 그림과 핵심 비교 중심. 학습곡선·FT/KD·배포·추적 원리·PC 옵션·제어 상세·화면 지연은 예비자료로 이동.
- 녹화 재생 화면·합성 GUI·개념도를 각각 표시. 실제 옥상 추종 성과로 사용하지 않음.
- 세부 조건과 설명은 발표 대본 및 출처 문서에 보존. 팀원 원본은 수정하지 않음.
