11월 19일 판 발표에 넣은 내용의 근거입니다. 기준은 [model-bank `6ee8022` 박스 표시 문서](https://github.com/lwir-deepx-tracking-system/model-bank/blob/6ee8022c82d741b92631aa2561fdd89a26b8b84e/tracking_server/docs/box-display-2026-11-19.md)와 [같은 시점 인계](https://github.com/lwir-deepx-tracking-system/model-bank/blob/6ee8022c82d741b92631aa2561fdd89a26b8b84e/HANDOFF.md)입니다. 장치 상태는 기록 당시 값입니다. 그 뒤 바뀐 것(재학습 후보, 분할 C++ 이식, 짐벌, 11월 20일 장치 재설치)은 [11월 20일 추가 근거](근거_최신_20261120.md)에 있습니다.

## 상체 E10: 자체 라벨 650장 (발표 18쪽)

- **입력·정답:** 새 현장 439장(4명 영상)과 기존 검수 211장, 합계 650장입니다. 수동 MOT 사람 박스와 이전 상체 검출 후보를 대조해 새 상체 박스 743개를 만들었습니다. 기준에 맞지 않거나 중복·모호한 후보는 뺐습니다.
- **학습:** 시작 가중치는 F(`C_control_v1_epoch2.pt`, 예전 문서의 '공용 E2')이고 10 epoch 학습한 마지막 가중치를 씁니다(검증으로 고르지 않음). seed 0, batch 4, AdamW 2e-5, AMP 끔입니다. 라벨이 없는 사람 영역은 분류 손실에서 뺐고, 검수하지 않은 관절은 감독하지 않았습니다. 검수 264장 V7·V8 실험과는 다른 갈래입니다. 출처: [model-bank 31ac21b LWIR650_E10_CLAHE_REPRO_20261120.md](https://github.com/lwir-deepx-tracking-system/model-bank/blob/31ac21bfa4ff4f40896677d0bb9501f9e2f6ebab/tracking_server/models/detect/yolo26m/LWIR650_E10_CLAHE_REPRO_20261120.md)(기록 `7e4ed20`).
- **평가:** OTP2 검증 934장에서 이전 1,056장 E10 → 새 상체 E10: 상체 박스 AP50–95 **36.04 → 46.28%**, 관절 AP50–95 **77.28 → 78.35%**, 박스 재현율 **71.70 → 69.09%**입니다. 공개 검증셋 평가이며 장치에서 잰 독립 성능은 아닙니다. [검증 CSV](학습로그/20261119_E10_OTP2_validation.csv)는 원본 숫자를 옮긴 것입니다.
- **현장 사례:** seq_002의 세 프레임, 전체·분할 두 입력에서 이전 중복 11건이 사라졌다는 CPU 비교가 있습니다. 이 프레임은 현장 학습 범위와 겹치므로 일반화 성능으로 읽지 않습니다.
- **장치 상태(11월 19일):** 8090의 추천 검출기가 되었고 NPU 0·1 한 장 분할과 BoT-SORT로 실행했습니다(model-bank 31ac21b HANDOFF.md '8090 후속 적용').
- 원본: 작성자 PC 기록(비공개): `RESULT_KO.md`, `OTP2_FIXED_EVAL.json`(상체 E10 학습 폴더).

## 추가 3 epoch과 시간 손실 (발표 18쪽 오른쪽)

상체 E10에서 같은 650장으로 3 epoch(126회 갱신) 더 학습한 두 갈래입니다. 하나는 일반 추가 학습(대조), 하나는 두 프레임의 박스 이동량 차이를 줄이는 시간 손실을 넣은 것입니다. 학습에는 130쌍을 썼습니다. 수동 박스 29쌍은 중심·폭·높이 변화를, 관절로 움직임을 확인한 101쌍은 중심 변화만 씁니다. 학습 뒤 채점은 그중 129쌍에서 했습니다(원본 기록의 수 그대로).

| OTP2 934장 검증 | 시작 E10 | 3 epoch 대조 | 3 epoch 시간 손실 |
| --- | ---: | ---: | ---: |
| 박스 AP50–95 | 46.28% | 40.23% | 40.21% |
| 관절 AP50–95 | 78.35% | 74.58% | 74.58% |

- 두 조건의 AP가 비슷하게 떨어졌으므로 하락을 시간 손실 탓으로 볼 수 없습니다. 두 조건 모두 E10보다 단순한 증강을 써서 하락 원인도 나뉘지 않습니다.
- 학습에 쓴 129쌍의 중심 이동 오차 p95는 11.43 → 11.15(대조) → 11.14 px(시간 손실)로, 두 조건 차이는 약 0.013 px입니다. 수동 28쌍은 두 조건 모두 20.99 → 21.19 px로 나빠졌습니다. **시간 손실의 효과는 어디에서도 확인되지 않았습니다.**
- E10보다 낫다는 근거가 없어 운영 교체를 보류했고, 11월 19일 14시에 장치 선택 목록에서 숨겼습니다(model-bank `2087d16`, 이름 E13).
- 원본: 작성자 PC 기록(비공개): `RESULT_KO.md`, `VALIDATION.json`(E10 이어 학습 대조).

## 화면에서 상체·전신 표시 (발표 25쪽)

상체 박스와 관절로 전신 범위를 **표시용으로만** 계산합니다. 발목이 보이면 발목을 쓰고, 없으면 무릎, 그다음 선 사람 비율을 씁니다. 전신 표시로 바꿔도 ID 매칭, 추적 채점, 짐벌 조준은 상체 추적 좌표를 씁니다.

- E10의 `seq_003` 56장·190개 대응 박스에서 전신 정답과의 중앙 IoU는 0.427 → 0.744, 밑변 중앙 오차는 60.4 → 4.8 px였습니다. **190개 모두 발목이 보인 경우**여서 무릎이나 하체 가림 때의 정확도는 평가되지 않았습니다. 상체 박스와 전신 정답은 크기 정의가 달라 이 수치를 검출 AP 개선으로 읽지 않습니다.
- 발표 사진은 장치에서 실제 열화상 녹화를 재생한 화면입니다(작성자 PC 기록(비공개): `BOARD_POSE_UPPER_REPLAY.jpg`, `BOARD_POSE_FULL_REPLAY.jpg`). 두 사진은 서로 다른 프레임이어서 같은 검출을 두 방식으로 그린 비교가 아닙니다.
- 공개 코드: 중복 판정 `pose_duplicate.py`는 11월 20일 기록 `1cb5998`부터 공개 트리에 있습니다. 전신 계산 `pose_full_box.py`는 31ac21b 공개 트리에 아직 없습니다.

## NPU 0·1 한 장 분할 첫 측정 (발표 29쪽, 부록)

입력 640×480을 폭 384 px 타일 두 개로 나누고 가운데 128 px를 겹칩니다. NPU 0과 1이 같은 프레임을 동시에 처리하고, 원래 화면 좌표로 옮겨 합친 뒤 사람 NMS를 합니다([model-bank 6ee8022 dual_tile.py](https://github.com/lwir-deepx-tracking-system/model-bank/blob/6ee8022c82d741b92631aa2561fdd89a26b8b84e/tracking_server/src/detect/dual_tile.py)).

- 11월 19일 첫 비교는 **E10+3 시험 모델**로 했습니다. 실카메라 약 30 FPS, 각 65초, 서버 수신→추적 완료 p95가 프레임 교대 40.47 ms(표본 1,800개, 큐 버림 0), 한 장 분할 25.71 ms(1,799개, 큐 버림 1)였습니다. 처리 순서 오류는 둘 다 0이었습니다. 브라우저 표시와 짐벌 응답은 이 구간 밖입니다. 녹화 재생 310장·32.47 ms는 별도 시험입니다.
- 이 비교 뒤 분할은 운영 모드가 되었고 C++로 옮겼습니다. 이후 수치와 "모든 장 33 ms 이내" 기준의 결과는 [11월 20일 추가 근거](근거_최신_20261120.md) 2절에 있습니다.
