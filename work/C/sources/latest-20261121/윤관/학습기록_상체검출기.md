## 1. YOLO26m FLIR 열화상 30 epoch (11-01, 범용 검출기의 바탕)

- **왜.** 사용자 문장은 기록 없음. 스크립트 머리말: "앞서 FLIR 4,196장으로 학습한 m 교사의 설정을 그대로" 쓰되 자료만 10,491장으로 늘림. s에서 m으로 옮긴 이유를 적은 문서는 못 찾음. 출처: 개인 실험 기록(`train_full.py`), [근거_30epoch.md](근거_30epoch.md).
- **데이터.** FLIR 학습 10,491장, 검증 1,144장(사람 4,470명).
- **순서.** COCO 사전학습 → FLIR 전체 가중치 30 epoch 한 번.
- **설정.** AdamW lr0 3e-4(마지막 0.01배, cosine), 워밍업 3 epoch, batch 8(nbs 64), 크기 증강 0.75, 모자이크 1.0(마지막 10 epoch 끔), 색상·채도 변화 끔, seed 202, AMP 켬(스크립트 머리말의 FP32와 다름). 시작·완료 사이 약 2시간 2분(GPU를 YOLO26x와 나눠 씀).
- **손실 곡선.** 학습 상자 손실 1.843(1 epoch) → 1.455(30), 분류 손실 1.403 → 0.797. [YOLO26m_FullFT_30epoch_lr_loss.csv](학습로그/YOLO26m_FullFT_30epoch_lr_loss.csv).
- **결과.** 사람 AP50–95: 1 epoch 43.75, 모자이크를 끈 21 epoch 49.75, **27 epoch 최고 50.75**, 30 epoch 50.62. 같은 검증셋으로 최고를 골랐으므로 독립 시험이 아님.
- **왜 채택.** 같은 설정의 앞선 s·m 교사와 같은 레시피이고 27 epoch 이후 정체. 비교 대안(다른 길이)은 돌리지 않음.
- **모르는 것.** 30 epoch가 최적 길이인지, 크기 증강 0.75의 효과를 따로 잰 기록.

## 2. 공개 자료 단계 A → E → R1 → C (11-14~15, Vast RTX 5070 Ti)

- **왜.** 계획 문서의 문장: "근거리와 원거리를 한 모델(YOLO26m-pose, 머리~엉덩이 몸 상자)로 처리하고, 가려진 사람(책상·모니터 뒤, 화면 밖으로 잘림)에 강하게 만든다." 1단계 이유: "몸 모양은 컬러 자료가 가장 많음, 흑백은 우리 입력(회색 1장을 3채널로)과 같은 모양, MOT17은 가림이 많음". 출처: model-bank b20d481 research/lwir_pose_plan/README.md 1·7절.
- **데이터(장수).** OTP2 근거리 열화상 자세 8,846 · COCO 흑백 30,000 · MOT17 흑백 2,536 · LLVIP-Pose 6,851. 모두 공개·연구용.
- **순서.** 공개 YOLO26m-pose → A(OTP2) → … → D(흑백 COCO) → E(+MOT17, 4 epoch 판이 장치 기본이 됨) → R1(+LLVIP-Pose 10 epoch) → C(R1에서 6 epoch, 가림 합성 묶음 없는 대조). 중간에 O(사무실 가림 조각 974개 섞음)와 대조 C를 같은 양으로 비교.
- **설정.** AdamW, 640 입력, batch 16, nbs 64, 워밍업 1 epoch, 끝 학습률 0.1배, 모자이크 끔, 회전 ±5°·이동 20%·크기 ±50%·좌우 반전, 몸 일부만 보이게 하는 부분 학습 확률 0.5, 가림 합성 0.5, 열화상 밝기·흐림. lr: D·E·R1 2e-4, C·O 1e-4. 설정 이유 표: 부록 `자세 모델 학습 설정`.
- **손실 곡선.** C(6 epoch): 상자 1.418 → 1.377, 관절 2.471 → 2.345, 분류 1.196 → 1.129. 검증 점수는 단계마다 검증 묶음이 달라 이어서 비교하지 않음. [상체_공개학습단계_epoch별.csv](학습로그/상체_공개학습단계_epoch별.csv).
- **결과와 결정(결정에 쓴 비교만).** 
  - E 대 F(공개 시험): OTP2 관절 80.4 → 85.1, TMOT 검증 HOTA 19.5 → 32.8, 작은 사람(키 25~50 px) 찾음 7% → 41%. 우리 실내는 E가 51%, F 48%(녹화 2개라 우연 범위).
  - F(= C epoch2) 대 O 마지막: 실내 찾음 48 대 49, 원거리 94 대 94, 실내 헛상자 0.07 대 0.19 → 헛상자가 3분의 1인 C를 택함.
  - 오래 학습할수록 공개 시험은 오르고 우리 실내는 내렸음(R0 43%, R1 42% 대 E 51%).
- **왜 채택.** F를 원거리 선택지로, E를 기본으로 둠. 출처: README 7-5·7-6절.
- **모르는 것.** 공개 시험은 같은 카메라 묶음으로 학습해 유리함(LLVIP-Pose). 11-16 마지막 미세조정 첫 후보(NF)는 가까운 사람 98.59 → 93.64, 실내 가짜 상자 0.068 → 0.152로 규칙에서 탈락해 변환하지 않음(README 7-7절, 부록 `자체·공개 혼합 학습`).

## 3. 현장 650장 E10 (운영 검출기)

- **왜.** 사용자 문장은 기록 없음. 모델뱅크 안내: "10에폭의 last.pt에서 내보낸 상체 박스와 관절 17개 모델"이고 11-17 검수 264장 E10과는 별도 학습입니다. 계획 문서의 3단계("우리 카메라: 손 라벨 … 쓰는 카메라 라벨이 효과가 가장 큼")에 해당하는 학습으로 보이나(추정) 650장 학습만의 사용자 문장은 없음. 출처: model-bank b20d481 tracking_server/models/detect/yolo26m/LWIR650_E10_CLAHE_REPRO_20261120.md.
- **데이터.** 학습 650장(검수 세트 상체 211장 + 4명 영상 439장), 학습 중 확인 OTP2 934장, 별도 시험 OTP2 2,151장. 학습·검증·시험 사이 바이트·픽셀이 같은 이미지는 0장(유사 장면은 판정 못 함).
- **순서.** F(`C_control_v1_epoch2.pt`)에서 시작 → 650장으로 10 epoch 한 번.
- **설정.** seed 0, batch 4, AdamW, 초기 lr 2e-5(cosine 끝 약 2e-6), 워밍업 1 epoch, AMP 끔(FP32), 가림 합성 0.15, 부분 학습 0.5. 손실 = 박스 + 관절(+RLE) + 관절 보임 + 분류.
- **손실 곡선.** 원 학습 로그(`TRAIN.log`)는 팀 보관본 tar 안에만 있어 이 자료에는 없음. 같은 코드·인자·시작 가중치로 11-20 다시 돌린 대조 학습의 곡선으로 대신 보임: 상자 1.998(1 epoch) → 1.451(10), 관절 1.401 → 0.985. 이 실행은 10 epoch 끝에서만 검증. [상체_650장E10재현_학습손실.csv](학습로그/상체_650장E10재현_학습손실.csv).
- **결과.** OTP2 934장 박스/관절 mAP50–95: F 30.88/84.35 → **E10 46.28/78.35**(박스 +15.4, 관절 −6.0, 부록 `검수 264장 학습`의 F 값). 별도 시험 2,151장 E10 46.02/78.78.
- **왜 채택.** 장치가 상체 박스로 조준하므로 박스가 큰 폭으로 오른 것을 택함. 이후 모든 교체 후보(2·4~8절)가 박스·관절을 함께 못 이겨 유지.
- **모르는 것.** 650장 모델을 등록하기로 한 날짜와 사용자 문장, 같은 시기 AUG E01(검수 264장, OTP2 박스 52.09)이 박스는 더 높았는데도 E10을 운영에 둔 결정 기록 — 못 찾음(HANDOFF는 "교체 후보 우위 없음"만 적음). 11-17 E10(검수 264장)과 이름이 같아 헷갈리기 쉬움.

## 4. E10 + 3 epoch, 시간 손실 시험 (E13)

- **왜.** 사용자 문장은 기록 없음. 11-15 계획: 박스 흔들림은 26m이 아니라 별도 시간 모델로 줄이기로 합의. 11-17 이후 같은 사람의 연속 프레임에 정답 움직임을 따라가는 시간 손실(가중치 0.5)을 26m 학습에 넣은 시도가 이 줄과 5절입니다. 출처: README 2·7절, HANDOFF 11-17.
- **데이터·순서·설정.** 같은 650장에서 E10 → 3 epoch 추가 + 시간 손실. 학습률·배치 기록은 이 자료에 없음(partial).
- **손실 곡선.** 기록 없음.
- **결과.** 고정 OTP2 박스 mAP50–95 **46.28 → 40.21**.
- **왜 보류.** 박스 점수가 6.1점 떨어져 모델 선택 목록에서 숨김(파일은 보존). 출처: HANDOFF 11-19.
- **모르는 것.** 흔들림이 실제로 줄었는지 잰 값, 학습 설정 전체.

## 5. 검수 264장 V7 → V8 → 11-17 E10 (시간 손실 포함)

- **왜.** 사용자 문장은 기록 없음. 검수가 끝난 264장(실내 192·실외 72)만으로 상체 박스·관절을 맞추기 위함.
- **순서·설정.** F에서 V7: 같은 264장 24 epoch(cosine). V8: V7에 증강 + 시간 손실. 11-17 E10: 10 epoch, seed 0, batch 4, FP32, AdamW(wd 5e-4) cosine 2e-5 → 2e-6, 갱신 679회, 시간 손실 0.5, 같은 사람 연속 프레임에 반전·확대·흐림·명암·가림을 공유 적용, 모자이크·MixUp 끔. GTX 1080 Ti.
- **손실 곡선.** V7 24 epoch 곡선은 [상체_공개학습단계_epoch별.csv](학습로그/상체_공개학습단계_epoch별.csv)의 `V7`행. 11-17 E10은 손실 기록 없음(체크포인트와 해시만).
- **결과(OTP2 934장, F → V7 → V8).** 박스 30.88 → 52.51 → 52.09, 관절 84.35 → 73.06 → 71.94, 20–32 px 사람 놓침 48 → 64 → 92건.
- **왜 보류.** 박스는 올랐지만 관절·작은 사람이 F보다 나빠 사전 기준 탈락. 11-17 E10은 "실기 비교용 시험판"으로만 등록.
- **모르는 것.** V8에서 시간 손실만 따로 뺀 대조는 기록 없음.

## 6. 11-19 교체 후보 재학습 (578장)

- **왜.** E10을 이길 후보를 찾기 위해(사용자 문장 기록 없음). 자체 703장을 촬영 단위로 학습 578 · 검증 63 · 시험 62로 나눔. E10은 시험 62장 중 61장을 학습에 써서 OTP2 934장으로 비교.
- **순서·설정.** 공개 E02(= F)에서 시작. 모두 Vast RTX 5070 Ti. (a) E10 방식 그대로(FP32, AdamW 2e-5) (b) 표준 증강, 낮은 학습률 5e-6 / 높은 5e-5(BF16) (c) 강한 증강(크롭·가림 0.28·회전 ±10°) (d) 직각 회전 10% (e) 사람별 열 대비 증강(확률 0.45, 12 epoch, lr 1e-5) (f) 관절만 학습 (g) 박스·관절 가중 학습.
- **손실·검증 곡선.** 낮은 학습률: 검증 박스 AP 50.1(5 epoch) → 53.1(11), 높은 학습률(BF16)은 53~56 사이에서 오르내려 30 epoch까지 뚜렷한 추세 없음. [상체_578장재학습_검증곡선.csv](학습로그/상체_578장재학습_검증곡선.csv).
- **결과(OTP2 934장, E10 46.28/78.35 기준).** E10 방식 재학습 38.88/81.44 · 열 대비 40.31/80.55 · 표준 증강 48.16/77.31 · 강한 증강 45.37/78.86 · 직각 회전 44.68/79.27. 새 E10은 45.96/78.11로 원래 E10(46.28/78.35)과 거의 같음 = 같은 설정이 재현됨.
- **왜 보류.** 박스가 오른 후보는 관절이 내려가고(표준 증강 +1.9/−1.0), 관절이 오른 후보는 박스가 내려가(−6~−7) 함께 이긴 것이 없음. 관절만 학습은 직접 박스 36.76 대 관절 계산 박스 25.02로 계산 박스가 짐.
- **모르는 것.** OTP2는 같은 카메라가 아니라 "현장 성능"의 직접 근거가 아님. 현장 시험 62장은 양성이 20명뿐.

## 7. HOTA 비교 (11-19)

- **왜.** 박스 AP가 아니라 번호가 붙은 결과로 후보를 고르기 위해: 같은 BoT-SORT와 ID 판정을 고정하고 검출기만 바꿈.
- **데이터.** 검수 실내 녹화 394장, 자체 야외 853장(분할 모사).
- **순서·설정.** AUG E01(검수 264장)에서 시작해 Vast 55장 파인튜닝 2→4→추가 epoch. 일반 증강 대 박스 아래쪽 가림 증강 대 초점 이탈 증강을 같은 방법으로.
- **결과.** 실내 HOTA: E10 29.05 → Vast E05 **37.50**, 야외: E10 **44.91** → E05 41.92. E10에서 시작해 실내 55장+야외 35장을 합쳐 1 epoch 학습하면 29.09 / 44.66으로 거의 그대로. 박스·관절 보정기는 E10 29.05보다 낮은 26.88·26.49.
- **왜 보류.** 실내·야외를 함께 앞선 후보가 없음 → E10 유지.
- **모르는 것.** 야외는 사람이 직접 수정한 박스가 많아 기준이 다름. 보드 INT8 정확도와 지연은 후보마다 재지 않음.

## 8. CLAHE 대조 학습 (11-20)

- **왜.** 열화상 대비 보강(CLAHE)이 학습에 도움이 되는지 보려는 비교. 출처: model-bank 재현 안내의 "다음 비교 계획".
- **설정.** 650장 E10 레시피 그대로, 학습 로더에만 CLAHE를 켠 쪽과 끈 쪽을 seed 0으로 각 10 epoch. 시작은 F.
- **결과(OTP2 검증 934장 / 시험 2,151장, 박스·관절 mAP50–95).** 원래 E10 46.28/78.35 · 46.02/78.78, 재학습 대조 44.45/78.78 · 44.40/79.40, **CLAHE 학습 45.11/78.47 · 45.19/79.12**. CLAHE로 입력을 바꿔 채점해도 대조 47.20 대 CLAHE 46.87.
- **왜 보류.** 대조와 CLAHE의 차이(박스 +0.7~0.8)가 원래 E10과 재학습 대조 사이의 차이(−1.8)보다 작아 효과를 말할 수 없음.
- **모르는 것.** 재학습이 원래 E10보다 1.8점 낮은 이유(AMP·난수·코드 버전 가능성)는 확인 못 함. [상체_650장E10재현_학습손실.csv](학습로그/상체_650장E10재현_학습손실.csv)에는 곡선만 있고 결과는 위 값.
