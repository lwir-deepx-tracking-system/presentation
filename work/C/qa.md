# C안 예상 질문

최신 상태·모순을 먼저 정리했다. 아래 기존질문은 새판정과 충돌하지 않는 범위에서 활용한다.

## 01. 최신 추천 검출기와 외형 모델은 무엇인가요?

11/22 모델뱅크 추천은 own9e 시드1과 기본 RVGGA0_REID2C256입니다. own9e는 장치 재생18편에서 IDF1 +4.50%p였으나 어깨 신뢰도 기준 충족률은92→9%였습니다. E10 AP46.28%는 앞선 별도 평가 결과입니다.

근거: S26, S27

## 02. 최종 추적 알고리즘은 무엇인가요?

최종 알고리즘은 BoT-SORT입니다. ByteTrack과 OC-SORT는 구현·평가한 비교 후보로 설명합니다. 동일 PC에서 HOTA 60.7, IDF1 67.5%, MOTA 74.7%를 확인하고, 최종 파라미터 조합을 선정했습니다. OC-SORT의 ID 변경531회와 재현율87.7%는 후보 장점으로 남깁니다.

근거: S24

## 03. 30 Hz 목표를 달성했나요?

일부 시험의 p95는 33 ms 아래지만 모든 프레임 기준은 통과하지 못했습니다. 장시간 18,497장 중 5장이 초과했고 최대 44.582 ms입니다. 최종 시스템 종단 30 Hz 성능을 입증하지 않았습니다.

근거: S17

## 04. 현재 장치도 25.71 ms인가요?

11/19 E10+3 모델로 재설치 전에 잰 65초 서버 시험입니다. 재설치 뒤에는 전체 화면 실행과 높은 초과율이 기록됐고, 이후에도 복구·변경이 있어 최종 실행을 별도로 확인해야 합니다.

근거: S17

## 05. CMC 때문에 BoT-SORT가 좋았나요?

해당 v3 수치 비교에서는 CMC와 ReID를 사용하지 않았습니다. 카메라가 움직이는 시스템에서 적용을 검토할 이유와 해당 시험의 성능 원인을 구분합니다.

근거: S24

## 06. 표준 증강 AP가 높은데 왜 E10을 유지했나요?

OTP2 박스 AP는 48.16%로 높지만 관절은 77.31%로 낮고, 실내·실외 추적을 함께 이긴 후보가 없었습니다. 자체 시험에는 E10 학습 노출이 있어 그 점수로 일반화 우위를 단정하지 않습니다.

근거: S17

## 07. GRU가 Kalman보다 좋나요?

공개 검증에서 위치 오차가 낮아 GRU를 적용했습니다. 자체 14편 위치 오차는 Kalman 0.110, 수정 GRU 0.122였고, 장치 재생 한 편 IDF1은 Kalman 71.81%, GRU 75.36%였습니다.

근거: S20

## 08. 번호 가드 두 개면 모든 지표가 좋아지나요?

9편 PC 비교에서 장기 번호 뺏김은 20→17이지만 IDF1은 82.3%로 같고, cost_first만 켠 83.2%보다 낮습니다. 장치 효과와 CPU 비용은 미측정입니다.

근거: S17

## 09. SOLIDER 증류 E가 기본인가요?

시험용 추가 선택지입니다. 라벨 9편 PC IDF1은 82.4%로 기존 83.0%보다 낮았습니다. 실내 4명 장면의 이득을 전체 성능으로 확대하지 않습니다.

근거: S18

## 10. 증류 교사가 LUPerson 원본인가요?

11/10·15 교사는 ThermalTrack 공개 열화상 재식별 가중치입니다. LUPerson RGB 자기지도 원본은 11/20 파인튜닝 시작점입니다.

근거: S18

## 11. 예측 추종이 재포착을 20%p 높였나요?

가상 비교의 vel 결과입니다. 장치 기록의 fused는 +6%p이고 95% 구간이 0을 포함합니다. 실제 사람·실제 짐벌의 재포착 개선은 입증하지 않았습니다.

근거: S17

## 12. 짐벌 지연이 약 200 ms인가요?

약 190~210 ms는 과거 일부 실측과 추정을 합친 값입니다. 명령부터 화면 반응까지 108 ms는 직접 실측이지만 장면부터 짐벌까지의 최종 종단 실측은 없습니다.

근거: S17

## 13. INT8 aggressive 옵션을 분할 모델에도 썼나요?

아닙니다. 29.10→21.92 ms는 과거 FLIR YOLO26s 시험이고 분할 파일은 CPU 부분 0, aggressive 미사용입니다.

근거: S17

## 14. 박스 보정으로 조준도 좋아졌나요?

키 변화는 0.071→0.043이지만 조준 떨림은 0.0195로 같았습니다. 기본 body이며 변환표가 없으면 size, 오류 시 자동 비활성화가 가능합니다. 장치 적용과 현장 효과는 별도 확인 대상입니다.

근거: S26

## 15. FastTrackTr를 최종 추적기로 썼나요?

열화상 이어 학습으로 TMOT 6편 IDF1이 15.3→27.1%로 올랐지만 성능 부족으로 중단해 시험 선택지로만 유지했습니다.

근거: S21

## 16. 기본 PD와 새 짐벌 개선의 담당은 누구인가요?

팀 역할 원문을 따릅니다. 기본 PD·GUI·짐벌 제어는 윤오름, 윤관 자료는 그 위의 모델 학습·튜닝·실측·가상 시험 근거입니다.

근거: S13

## 기존 설계·운용 질문

## 13. PID 대신 PD를 선택한 이유는 무엇인가요?

I항은 누적 오차를 보정하지만 이번 장치의 지연·정지 뒤 밀림에서는 넘침과 반복 반전을 키울 수 있었습니다. 11-10 실물+가상표적 시험에서 PID30/5/1과 PID30/1/6(적분 한계1) 후보는 세로8회 반전하며 끝까지 안정되지 않았다고 기록됐습니다. Ki=0과 D·불감대 조정으로 안정성을 우선했습니다. 설정 여러 개를 비교한 시험이므로 I만의 원인을 분리한 결론이나 모든 PID의 열등함을 뜻하지 않습니다.

근거: S16

## 25. I항을 빼면 어떤 단점이 있나요?

누적 보정이 없어 일정하게 남는 오차를 없애는 능력이 줄 수 있습니다. 이번 설정은 불감대 안의 잔류 오차와 이동 표적 뒤처짐을 허용하면서 반복 반전을 억제하는 선택입니다. 0오차·모든 속도의 추종을 달성했다고 설명하지 않습니다.

근거: S16

## 26. 적분 제한을 넣으면 PID도 가능하지 않나요?

가능한 개선 방향입니다. 기록의 PID30/1/6 후보도 적분 한계1을 사용했지만 시험에서 안정되지 않았습니다. 현재 결과는 시험한 후보 안에서 PD를 선택한 근거이며, 다른 anti-windup·지연 보상·튜닝으로 PID가 불가능하다는 증거는 아닙니다.

근거: S16

## 27. 반전 4회에서 1회는 I항을 뺀 효과인가요?

아닙니다. 해당 stage7 비교는 Kp30·Ki0·Kd6을 고정한 채 불감대0.04와0.06을 비교한 실제 장치+가상표적 시험입니다. PD 선택 근거와 불감대 조정 효과는 다른 비교입니다.

근거: S16

## 30. 전신 박스로 표시하면 조준점도 바뀌나요?

표시용 전신 범위만 바꾸며 ID 매칭·평가·짐벌 조준은 상체 추적 좌표를 유지합니다. 190개 표본은 모두 발목이 보였고 하체 가림 성능은 미확인입니다.

근거: S15

## 32. GUI에서 추적기 변경은 어떻게 확인하나요?

PC가 추적기 번호를 TCP로 요청하고 Runtime은 카탈로그 설정으로 생성해 프레임 경계에서 교체합니다. Accepted와 Completed를 구분하며 생성 실패 시 기존 추적기를 유지합니다. 교체 뒤 선택 ID 처리와 실제 화면은 최종 데모 설정에 맞춥니다.

근거: S14
