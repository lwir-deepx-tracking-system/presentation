# 취합 결정과 옥상 시험 후 교체할 곳

## 취합 원칙

- 본문18장/20분, 데모180초 포함. 구현 설명과 정량 결과를 함께 배치.
- 사용자 자료의 시스템·제어·GUI를 뼈대로, 윤관의 검출·배포·제어 시험과 정하건의 동일검출 추적 결과를 중심 근거로 사용.
- 김재남의 C++ Runtime 큐 수치를 Python 서버의 내부 구조로 옮기지 않고, 하드웨어 역할·전후처리·통신 경계 설명을 활용.
- 윤관39/66장은 학습·질의응답 근거로 보존하고 중복 학습설정·시험나열을 본문에서 축약.
- 정하건 긴 버전은 원리·실험 근거로 보존하고 본문에 원리+동일보드비교+동일PC옵션 세 장을 배치.
- 홍정호 폴더에 대본이 없으므로 윤관의 배포 근거로 INT8 단계를 설명. 독립 담당 성과로 새 수치를 만들어 넣지 않음.

## 최종 확정표

| 교체 위치 | 필요한 입력 | 현재 처리 |
|---|---|---|
| 05·16 | 후보 A/B의 실제 파일명·버전 | 임의로 s/m 또는 F/NF와 대응하지 않음 |
| 13 | 실제 브리지와 제어 인자 | 공개기본값과 과거튜닝 구분 |
| 14 | 실제운용 캡처·영상 모드 | 합성 GUI라 명시 |
| 16 | 옥상 비교규칙·반복·결과 | 결과 미작성 |
| 17 | 180초 이내 데모 mp4 | 재생 화면 포스터+안내 |
| 18 | 최종 선택·결론 한 문장 | 과거 결과만 별도 집계 |

## 팀원에게 확인할 최소 항목

1. 윤관: 후보 두 개와 대표 검출 결과의 최종 버전·시험 조건.
2. 정하건: 옥상에서 실제 쓰는 추적기·옵션, 본문 비교표의 조건 확인.
3. 시연 담당: 모델·추적기·제어·영상 모드 고정한 촬영, FPS/드롭·끊김 기록.
4. 최종 발표자: 낭독+영상 포함20분 리허설.

## 데모 파일 넣기

`assets/rooftop-demo.mp4`를 넣고 브라우저에서 17번을 연다. 해당 경로가 생기면 슬라이드의 임시 안내도 `build.py`에서 확정 캡션으로 고치고 다시 생성한다. 영상 자체는 이 초안에 포함되지 않았다.
