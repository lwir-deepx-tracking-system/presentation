추가 옵션: Buffered IoU와 L1

ADDED OPTIONS

ByteTrack에서 효과가 컸던 두 기능을 OC-SORT에 옵션으로 이식했습니다.

A

Buffered IoU 0.5

OCR 뒤 남은 Track과 검출을
각 변 0.5배 넓혀 한 번 더 매칭

B

놓친 프레임 출력 (L1)

출력하던 Track이 1프레임 놓치면
같은 ID의 예측 박스로 이어서 출력

선택 이유

짐벌 운용에서는 표적을 잃는 ID 전환(−19%)과 박스 끊김(−15%)이 더 치명적이라 정밀도 1.1%p를 내주고 A + B 채택. 두 옵션 모두 끄면 공식 구현과 출력 동일
