# B안 · 화면 흐름을 따라가는 20분 발표

리팩터링·새 발표안 제작 전에는 [전체 요구사항과 인계](../HANDOFF.md)를 먼저 읽습니다. 표지에는 팀장 표기 없이 다섯 명 이름을 나란히 두고, 팀장 배지는 팀 소개 장에만 표시합니다.

본문 32장 + 예비자료 18장. 발표 17분 + 실제 데모 3분의 목표 시간표입니다. 실제 낭독 리허설은 아직 하지 않았습니다.

시작 순서는 **01 표지 → 02 팀 소개 → 03 운용 화면**입니다. 팀 소개는 사용자가 전달한 [담당 업무](team-roles.md)를 기준으로 주요 담당과 핵심 기여를 정리했습니다.

팀 소개는 윤오름에 `팀장` 배지를 표시하고, 각자 역할 두 줄만 남깁니다. 상세 구현 항목은 담당 업무 문서에 보존합니다.

실제 데모는 웹 GUI를 사용하지 않으므로 웹 화면·조작·전송 구조는 본문에서 제외했습니다. 실제 데모 앱의 GUI 캡처와 경로가 확인되면 24–26번을 맞춥니다. 이전 앱의 화면으로 임의 대체하지 않습니다.

**디자인 기준:** [공통 디자인·편집 기준](../DESIGN.md)을 따릅니다. 큰 제목은 `운용 화면` 같은 짧은 명사형 한 줄로 통일하며, 위쪽 작은 분류명을 중복 표시하지 않습니다. 새 수정과 다음 발표안도 이 기준을 유지합니다.

제목은 LIG 블루(`#002f6d`)로 표시합니다. 첫 장 표지 상단은 로고만 두고 별도 제목·구분선을 넣지 않습니다. 표지 본문은 공식 프로젝트 제목·팀명·팀원·멘토와 하드웨어 사진으로 구성하며 슬로건이나 시연 화면을 넣지 않습니다.

표지 정보: **DEEPX NPU를 이용한 LWIR 표적 추적 시스템 구현 / 5팀 올빼미 / 윤오름·김재남·윤관·정하건·홍정호 / 멘토 천준호 선임연구원**. 하드웨어 사진은 아직 삽입 자리이며, `assets/hardware-photo.jpg`를 추가한 뒤 build.py·render.py를 실행하면 반영됩니다.

LIG D&A 로고는 제목보다 작게 표시합니다(제목 50px, 로고 높이 34px). 제목 글자와 로고의 세로 중심 높이를 맞추고, 오른쪽 끝은 구분선 끝에 맞춥니다. 제목 아래 패딩은 22px, 로고 아래 여백은 33px로 선과 분리합니다. 원본 비율을 유지하며 본문·예비자료에 동일하게 적용합니다.

하단에는 페이지 표시만 둡니다. 초안 상태·팀명·프로젝트명·출처 링크 행·하단 구분선은 표시하지 않습니다. 출처와 미확정 사항은 대본·출처 문서·인계 문서에 보존합니다.

비교 결과(10·11·15·16·19·23번)는 막대그래프와 변화량으로 표시합니다. 막대는 0부터 시작하며, 개선과 악화를 함께 보여줍니다. 서로 다른 단위·시험은 그래프를 분리합니다.

실제 녹화 재생·합성 GUI·개념도는 구분해 표시합니다. 실제 통합 데모는 아직 없으며 28번은 영상 삽입 자리입니다. 거리·ID 유지 기준과 최종 현장 결과도 확정 전입니다.
