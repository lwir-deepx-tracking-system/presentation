# B안 · 화면 흐름을 따라가는 20분 발표

리팩터링·새 발표안 제작 전에는 [전체 요구사항과 인계](../HANDOFF.md)를 먼저 읽습니다. 표지에는 팀장 표기 없이 다섯 명 이름을 나란히 두고, 팀장 배지는 팀 소개 장에만 표시합니다.

본문 32장 + 예비자료 20장. 발표 17분 + 실제 데모 3분의 목표 시간표입니다. 실제 낭독 리허설은 아직 하지 않았습니다.

**11월 19일 보충:** 새 핵심 내용은 예비자료로 보내지 않고 본문에 반영했습니다. 단계별 설명 안에 그래프를 근거로 넣고, 마지막 장에서 결과와 적용 범위를 한눈에 정리합니다. 기존 예비자료는 보관용이며 본문 설명을 완성하기 위해 열어야 하는 자료가 아닙니다.

| 본문 | 문제 → 변경 → 확인한 결과 |
|---|---|
| 08–11 | 상체·전신 기준 혼재 → 현장 650장·라벨 누락 처리 → AP·재현율 절충 및 추가 학습 보류 |
| 18–19 | 처리 지연 → 두 NPU로 같은 프레임 동시 타일 → 실카메라 서버 p95 25.71ms·큐 버림 1장 |
| 20·24 | 표시 박스와 조준점의 혼동 → 상체 추적 좌표·전신 표시 분리 → 실제 녹화 재생 사례 |
| 31–32 | 측정 범위와 최종 운용의 혼동 → 측정 구간 표시·결과 지도 → 성과와 남은 검증 구분 |

새 근거는 [윤관 11월 19일 기록](../../윤관/근거_최신_20261119.md)이며 sources/latest-20261119/에 검증 CSV·이미지·원문·해시를 보존합니다. 새 상체 E10, 과거 FLIR 검출기, 별도 서버 동시 타일, C++ Runtime 시험을 같은 실행의 연속 개선으로 합치지 않습니다.

시작 순서는 **01 표지 → 02 팀 소개 → 03 프로젝트 소개**입니다. 팀 소개는 사용자가 전달한 [담당 업무](team-roles.md)를 기준으로 주요 담당과 핵심 기여를 정리했습니다.

팀 소개는 윤오름에 `팀장` 배지를 표시하고, 각자 역할 두 줄만 남깁니다. 상세 구현 항목은 담당 업무 문서에 보존합니다.

실제 데모는 웹 GUI를 사용하지 않으므로 웹 화면·조작·전송 구조를 데모 설명에 넣지 않습니다. 24번은 장치 열영상의 상체·전신 표시 사례이며 실제 GUI 캡처와 구분합니다. 정하건 v3 자료를 근거로 25–26번의 PC–Runtime TCP 추적기 변경 흐름을 유지합니다. 실제 데모 앱 캡처와 교체 후 표적 ID 정책은 최종 반영합니다.

최신 추적 근거는 [정하건 v3](../../정하건/정하건_v3/근거_비교표.md)입니다. 14–16번은 3종 구성·동일 PC 비교·장면별 선택 기준으로 갱신했습니다. 과거 보드 OC-SORT 775회 결과는 예비자료에 보존하고, 새 PC 결과 531/566회와 같은 실행으로 섞지 않습니다. 원문은 sources/tracking-v3-7249d7b/에 커밋·SHA256과 함께 보존합니다.

**디자인 기준:** [공통 디자인·편집 기준](../DESIGN.md)을 따릅니다. 큰 제목은 `운용 화면` 같은 짧은 명사형 한 줄로 통일하며, 위쪽 작은 분류명을 중복 표시하지 않습니다. 새 수정과 다음 발표안도 이 기준을 유지합니다.

제목은 LIG 블루(`#002f6d`)로 표시합니다. 첫 장 표지 상단은 로고만 두고 별도 제목·구분선을 넣지 않습니다. 표지 본문은 공식 프로젝트 제목·팀명·팀원·멘토와 하드웨어 사진으로 구성하며 슬로건이나 시연 화면을 넣지 않습니다.

표지 정보: **DEEPX NPU를 이용한 LWIR 표적 추적 시스템 구현 / 5팀 올빼미 / 윤오름·김재남·윤관·정하건·홍정호 / 멘토 천준호 선임연구원**. 하드웨어 사진은 아직 삽입 자리이며, `assets/hardware-photo.jpg`를 추가한 뒤 build.py·render.py를 실행하면 반영됩니다.

LIG D&A 로고는 제목보다 작게 표시합니다(제목 50px, 로고 높이 34px). 제목 글자와 로고의 세로 중심 높이를 맞추고, 오른쪽 끝은 구분선 끝에 맞춥니다. 제목 아래 패딩은 22px, 로고 아래 여백은 33px로 선과 분리합니다. 원본 비율을 유지하며 본문·예비자료에 동일하게 적용합니다.

하단에는 페이지 표시만 둡니다. 초안 상태·팀명·프로젝트명·출처 링크 행·하단 구분선은 표시하지 않습니다. 출처와 미확정 사항은 대본·출처 문서·인계 문서에 보존합니다.

비교 결과(10·11·15·16·19·23번)는 막대그래프와 변화량으로 표시합니다. 막대는 0부터 시작하며, 개선과 악화를 함께 보여줍니다. 서로 다른 단위·시험은 그래프를 분리합니다.

실제 녹화 재생과 개념도는 구분해 표시합니다. 두 표시 이미지는 서로 다른 프레임으로 정량 전후 비교에 쓰지 않습니다. 실제 통합 데모는 아직 없으며 28번은 영상 삽입 자리입니다. 거리·ID 유지 기준과 최종 운용 경로의 종단 결과도 확정 전입니다.
