# LWIR 프로젝트 발표자료

**DEEPX NPU를 이용한 LWIR 표적 추적 시스템 구현**

5팀 **올빼미**의 발표자료 저장소입니다. 각자 담당 폴더에 HTML·CSS·에셋·발표 노트를 직접 업로드하고, 최종 발표는 `final/`에서 취합합니다.

- 팀원: 윤오름 · 김재남 · 윤관 · 정하건 · 홍정호
- 멘토: 천준호 선임연구원
- 발표: 데모 영상 3분을 포함해 총 20분
- [발표 개요·공통 디자인 규격 — Notion](https://app.notion.com/p/4169de3f14a280ee9e05cec320dfb929)

## 폴더 구조

```text
presentation/
├── README.md
├── reference/          # 공통 디자인 안내·예시·로고·폰트
│   └── picture/          # 하드웨어·팀원 사진
├── 윤오름/             # 각자 담당 HTML·CSS·자료
│   └── assets/
├── 김재남/
│   └── assets/
├── 윤관/
│   └── assets/
├── 정하건/
│   └── assets/
├── 홍정호/
│   └── assets/
└── final/              # 최종 취합 HTML·PDF
```

폴더명은 자료 작성자를 구분합니다. 주제별 역할을 새로 배정한 것은 아닙니다.

## 업로드 방법

1. GitHub에서 **본인 이름 폴더**를 엽니다.
2. **Add file → Upload files**로 HTML·CSS와 필요한 에셋을 폴더 구조를 유지해 업로드합니다.
3. 변경 내용을 짧게 적고 `main`에 직접 반영합니다. 별도 브랜치와 PR은 필수가 아닙니다.
4. HTML 파일명과 담당 슬라이드 번호를 본인 폴더의 README에 기록합니다.
5. 업로드 전에 본인 컴퓨터에서 HTML이 열리고 이미지·폰트가 표시되는지 확인합니다.

Git으로 작업하는 경우에는 먼저 최신 내용을 받아 본인 폴더만 수정합니다. 다른 사람의 폴더나 저장소 전체를 덮어쓰지 않습니다.

## 작성 기준

- 각자 **독립된 HTML/CSS**로 작성해도 됩니다. 처음부터 하나의 HTML로 합칠 필요는 없습니다.
- 원본 슬라이드 크기는 **1920×1080px, 16:9**로 통일합니다.
- 흰색 배경, LIG 블루 `#002F6D`, Pretendard 폰트를 사용합니다.
- 슬라이드마다 `<section class="slide">`로 구분합니다.
- 우측 상단 로고와 헤더·푸터 위치는 공통 디자인 규격을 따릅니다.
- 이미지·폰트는 로컬 에셋으로 포함하고 상대 경로로 참조합니다. `C:\\...` 같은 개인 PC 절대 경로는 사용하지 않습니다.
- PDF 변환 시 슬라이드 한 장이 한 페이지에 들어가도록 합니다.
- 측정 수치에는 시험 조건과 출처를 함께 남깁니다. 기대 효과와 실제 측정 결과를 구분합니다.
- 상세 크기·디자인 기준은 [reference/README.md](reference/README.md)와 Notion을 참고합니다.

## 파일 예시

```text
윤오름/
├── README.md           # 담당 장·파일·실행 방법
├── index.html          # 발표 HTML, 다른 이름도 가능
├── styles.css
├── notes.md            # 발표 대본
└── assets/
    ├── diagram.svg
    └── screenshot.png
```

위 파일은 작성 예시입니다. 현재 초기 구조에는 README와 에셋 폴더 자리만 준비되어 있습니다.

## 최종 취합

각 담당자의 완성 자료를 발표 순서대로 합치고, 페이지 번호·용어·단위·출처 형식과 PDF 출력을 확인합니다. `final/`의 변경은 취합 담당자가 관리합니다. 대용량 원본 영상·데이터셋·모델 파일은 이 저장소에 넣지 말고 공유 위치를 담당 README에 기록합니다.
