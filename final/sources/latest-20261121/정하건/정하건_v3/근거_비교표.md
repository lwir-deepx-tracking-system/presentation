# 추적 알고리즘 슬라이드 근거 수치

모든 수치는 실제 실행 로그에서 나온 값입니다.

## 공통 조건
- 검출: YOLO26s, 같은 검출 결과로 추적기만 바꿔 비교
- 데이터: LWIR 실데이터 seq_001~018, 정답 직접 라벨링 (MOT 10열)
- 평가: TrackEval (HOTA, CLEAR, Identity). 합계는 18개 시퀀스 합산(COMBINED)
- 카메라 움직임 보정(CMC) 없음
- BoT-SORT는 외형 비교(ReID) 끔 (팀 추적 서버의 기본 'app: 끔'과 같음)

## 03쪽 · GUI 선택 구조 (근거: runtime 코드와 PC 통신 문서)
- config/runtime.yaml의 tracking_catalog 1 bytetrack.yaml · 2 ocsort.yaml · 3 botsort.yaml
- PC GUI 통신 확장 Pipeline 명령: 추적기 개수 조회(0x02 → 0x82), 추적기 변경(0x04 → 0x84, 접수 Accepted 후 완료 Completed)
- 생성 실패(CreationFailed) 시 쓰던 Tracker 유지, 교체는 런타임 루프가 프레임 경계에서 수행 (tracker_change_service, test_tracker_hotswap)
