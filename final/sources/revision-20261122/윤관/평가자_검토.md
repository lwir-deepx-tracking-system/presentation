# 윤관 발표자료 검토 메모 (2026-11-22)

## 발표 흐름 12장과 근거 자료

본문은 주요 결과와 담당 범위를 먼저 보여 준 뒤 상체 E10 → INT8·NPU 분할 → 외형·번호 유지 → 장치 안정화 → 가상 카메라와 짐벌 → 적용·보류 기준 순서입니다. 공개 데이터 파인튜닝, 실제 라벨링, FT·LoRA, 모델별 입출력과 학습 로그, 박스 생성 규칙은 전체 근거의 13장부터 확인할 수 있습니다.

| 확인할 부분 | 시험에서 확인한 범위 |
| --- | --- |
| 3장 · 상체 박스 | AP +10.24%p, 재현율 −2.61%p. 비교 모델은 학습 박스 기준이 다름 |
| 7장 · 가림과 ID 유지 | 수정 GRU 위치 오차 0.122, Kalman 0.110. 가드 추가 전후 IDF1 82.3% |
| 8장 · M1 지연 | 512×384의 p95 30.45 ms, 최대 63.09 ms. 33 ms 초과 16장, 기존 설정으로 복귀 |
| 9~10장 · 짐벌 | 가상 vel +20%p, 장치 설정 fused +6%p. 실제 짐벌 비교 중단 |
| 11장 · 모델뱅크 추천 | own9e는 18편 장치 재생 IDF1 +4.50%p, 양쪽 어깨 신뢰도 기준 충족률 92% → 9% |

짐벌의 PID 기본 구조와 GUI는 윤오름의 작업입니다. 윤관의 짐벌 기여는 튜닝·응답 실측·명령 지연 개선·놓침 대응입니다. 수치 출처는 [슬라이드별 근거](근거_슬라이드별.md)에 있습니다.

## 11월 19일 판에서 고친 것

- **학습 곡선:** YOLO26m 곡선은 학습 중 매 epoch 끝 EMA 가중치를 잰 값입니다. "학습 뒤 체크포인트 채점"이라는 설명을 고쳤고, 30 epoch를 정한 이유(모자이크 끄는 구간을 21~30 epoch에 맞춤)를 실행 스크립트 기록으로 적었습니다.
- **FT·LoRA:** 라벨 10%·30 epoch 값은 1,074장 묶음 세 개의 평균이고, 데이터 규모 장의 1,074장 점은 다른 실행(seed 202, 묶음 하나)입니다. LoRA는 r8에 검출 머리를 함께 학습한 형태입니다. 데이터 규모 장의 보간 점은 뺐습니다.
- **자세·상체:** 검수 264장 V7·V8 장에 시작 모델 F를 함께 그렸습니다. 현장 E10의 시작 가중치는 F이고, 관절이 모자란 사람의 비율 규칙은 이후 학습에서 꺼져 있었다고 적었습니다.
- **외형 모델:** 증류 비교의 B는 11-10 실내 튜닝 SOLIDER ep3를 고정 교사로 쓴 것입니다. 교사 파일을 확인했고, 검수 264장 RepVGG의 당시 장치 적용 이력과 11-20 교사 직접 비교(개선 없음)를 넣었습니다.
- **FastTrackTr:** INT8 보정은 16장을 썼고, 워밍업·학습률 낮추기는 실제 학습 설정입니다.
- **두 NPU 분할:** 첫 비교(40.47 → 25.71 ms)는 E10+3 시험 모델 값입니다. C++ 이식 뒤 값과 4명·고밀도 녹화 값을 함께 보이고, "모든 장 33 ms 이내"는 아직 못 맞췄다고 적었습니다.
- **짐벌:** 실측 응답, 가상 카메라 시험, 원거리 가속, 지연 예산, 놓침 대응을 새 장으로 넣었습니다. 켠 기능과 끈 기능, 근거가 약한 부분을 장마다 적었습니다.
- **공개 저장소:** 로컬 경로, 장치 주소, 장 안의 링크를 뺐습니다. 공개하지 않는 파일은 `개인 실험 기록(파일 이름)`처럼 파일 이름만 적었습니다.

## 11월 20일 장치 상태 (발표 수치와 다른 점)

11월 20일 오전 장치를 공개 main에서 새로 설치한 뒤, 장치에만 있던 두 가지가 빠졌습니다.

- 현장 650장 E10을 두 NPU 분할에 연결한 코드. 그 뒤 한 장 전체 방식으로 돌았고, 사람 없는 실카메라 12분 관찰에서 68.6%의 장이 33 ms를 넘었습니다. 같은 오전에 검출기 선택이 검수 264장 E10으로 바뀐 기록도 있습니다.
- 따라가던 사람에게 원래 번호를 되돌리는 KeepID 기능.

이 항목은 11월 20일 오전 상태입니다. 다른 시점의 분할 성능과 모델 선택은 각 시험 기록의 조건을 따릅니다. 자세한 내용은 [11월 20일 추가 근거](근거_최신_20261120.md) 5절에 있습니다.

## 평가자가 더 요청할 자료

1. **사람이 있는 실카메라 지연:** 분할 C++ 이식 뒤 사람이 있는 실카메라와 여러 명 자동 추종 측정이 없습니다. 지금 수치는 사람 없는 실카메라와 녹화 재생입니다.
2. **실제 사람·짐벌 재포착률:** 가상 시험의 vel과 장치의 fused 결과를 구분해야 합니다. 실제 짐벌 비교는 14분에 중단됐고 fused가 짐벌을 움직인 사례가 없었습니다.
3. **짐벌 실측 범위:** SPD 30 초과와 세로(틸트) 응답, 장면 → 짐벌 종단 지연(지금은 추정 190~210 ms)이 없습니다. 원거리 가속 설정은 PC 시뮬레이션으로 골랐습니다.
4. **양자화 전후 정확도:** 같은 가중치·입력의 FP32와 M1 INT8 정답 기준 정확도. 지금은 검출 일치 비교(99.2%)뿐입니다.
5. **독립 시험:** E10의 OTP2 2,151장 평가와 CLAHE 대조 학습은 실행했습니다. 현장 시험 62장 가운데 61장은 E10 학습에 들어 있었으므로 자체 카메라에서 독립 시험이 필요합니다.
6. **모델 선택 기록:** YOLO26m을 고를 때의 같은 조건 후보 비교와, m 교사 레시피를 처음 정한 이유.
7. **원본 학습 로그:** 자세 모델, 외형 증류, 위치 GRU·Mamba, FastTrackTr의 epoch별 기록. 이 폴더에는 YOLO26s FT·LoRA, 60 epoch FT·증류, YOLO26m 30 epoch, E10 OTP2 검증 로그만 있습니다.
8. **실물 자료:** 짐벌·카메라·보드 실물 사진과, 같은 시각의 영상·제어 명령·각도 기록.

논문은 방법의 원리를 참고한 자료이고, 이 프로젝트 결과의 근거는 저희 실험 기록입니다. 모델별 입력과 로그는 [모델별 입출력·로그](학습_입출력_로그.md)에 있습니다.
