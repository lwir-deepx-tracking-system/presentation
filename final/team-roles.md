# 팀원 담당 업무

사용자가 직접 전달한 담당 업무를 기준으로 정리했다. 기존 발표의 단순한 역할 추정보다 이 문서를 우선한다. 02번 팀 소개는 윤오름에 팀장 표기를 붙이고, 각자 핵심 역할 두 줄만 표시한다. 세부 업무 목록은 슬라이드에 나열하지 않는다.

| 팀원 | 발표용 역할 1 | 발표용 역할 2 |
|---|---|---|
| 윤오름 (팀장) | 시스템 설계 · 통신 | GUI · 짐벌 제어 |
| 김재남 | Runtime 구현 | 멀티스레드 파이프라인 |
| 윤관 | 적외선 모델 학습 | 경량화 · 최신 모델 조사 |
| 정하건 | 추적 알고리즘 | 성능 검증 · 개선 |
| 홍정호 | Runtime 최적화 | NPU · 추론 가속 |

## 윤오름

- 전체 시스템 아키텍처 및 PC–Orange Pi 통신 인터페이스 설계·구현: RTP/UDP 영상·메타데이터, TCP 제어.
- Qt 기반 PC GUI 구현: 실시간 영상·BBox 표시, Track ID 선택, 수동·추적 모드 선택.
- JPEG/H.264 영상 수신 및 FPS·지연·통신 상태 계측 기능 구현.
- PID 기반 짐벌 자동 추적 제어 알고리즘 구현.
- 개발 일정·업무 분장 및 GitHub 저장소·브랜치 통합 관리.

## 김재남

- 시스템 프로그래밍.
- 파이프라인·멀티스레드 설계 및 구현.
- Orange Pi 개발환경 구성.
- Runtime 코드 구현 및 충돌 병합.
- 리팩터링.

## 윤관

- 적외선 파인튜닝.
- 모델 경량화.
- 최신 모델 조사 및 구성.

## 정하건

- ByteTrack 기반 트래킹 알고리즘 구현.
- 검증용 알고리즘 구현 및 트래킹 알고리즘 검증.
- 검증 결과를 바탕으로 CMC, Fuse_score, biou 등 보완 알고리즘·옵션 구현 및 검증.
- 검증 결과 도식화·문서화를 통한 성능 개선 과정 기록.
- 짐벌 조립 및 데이터셋 구축을 위한 촬영 지원.

## 홍정호

- Runtime 최적화.
- 멀티스레딩 파이프라인 설계.
- 시간 측정 범위 설정.
- NPU format handler 가속화.
- ONNX 가속화.
- 지연 처리 성능 최적화.

팀원별 파이프라인·최적화 업무는 일부 겹친다. 역할을 서로 배타적인 영역으로 바꾸거나, 윤오름의 Qt 앱 기여를 웹 GUI 단독 개발로 바꿔 표기하지 않는다. 구현 상세와 최종 운용 설정은 관련 기술 슬라이드에서 구분한다.
