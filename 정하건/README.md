# 정하건 발표자료

본인 담당 HTML·CSS·이미지·발표 노트·근거 자료를 이 폴더에 직접 올립니다. 별도 브랜치와 PR은 필수가 아닙니다.

## 담당 자료

| 항목 | 작성 내용 |
| --- | --- |
| 담당 슬라이드 번호·제목 | 작성 시 기재 |
| 시작 HTML 파일 | 작성 시 기재 |
| 발표 노트 | 파일 또는 위치 기재 |
| 측정 결과·참고자료 | 출처 또는 위치 기재 |

## 파일 배치 예시

```text
정하건/
├── README.md
├── index.html
├── styles.css
├── notes.md
└── assets/
    ├── diagram.svg
    └── screenshot.png
```

HTML 파일명은 자유롭게 정할 수 있습니다. 초기에는 README와 에셋 폴더 자리만 준비되어 있습니다.

## 업로드 전 확인

- 슬라이드 크기는 **1920×1080px**.
- [공통 디자인](../reference/README.md)의 색상·폰트·헤더·로고·푸터 기준 적용.
- HTML을 열어 글자 잘림·이미지 누락 확인.
- 에셋은 이 폴더의 `assets/`에 넣고 상대 경로 사용.
- 발표 노트와 수치의 측정 조건·근거 포함.
- 담당 슬라이드와 파일 위치를 위 표에 기록.
- 다른 팀원의 폴더는 수정하지 않기.
