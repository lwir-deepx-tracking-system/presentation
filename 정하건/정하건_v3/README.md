# 추적 알고리즘 (정하건)

ByteTrack · OC-SORT · BoT-SORT 세 가지 구현, GUI에서 추적기를 바꾸는 구조, 성능 비교, BoT-SORT 최종 설정 5장입니다 (약 3분 30초). 공통 요구사항의 FHD(1920×1080) 규격을 따릅니다.

- `index.html`: 브라우저에서 열어 미리보기, 위 버튼으로 PDF 저장 (머리글/바닥글 끔, 배경 그래픽 켬, 여백 없음)
- `slides.css`: 1920×1080 레이아웃, LIG 블루 #002F6D, 인쇄 스타일
- `추적알고리즘_정하건.pdf`: 같은 HTML에서 출력한 PDF (5쪽)
- `발표노트.md`: 쪽별 발표 노트
- `근거_비교표.md`: 슬라이드에 쓴 모든 수치의 원본 표와 측정 조건
- `assets/fonts/`: Pretendard (OFL, 라이선스 동봉)
- `assets/logo/LIG_DNA.png`: **비어 있음.** reference 폴더의 공식 로고 `2_LIG_DNA(축약형).png`를 이 이름으로 복사하면 모든 쪽 우측 상단에 나옵니다.

도표는 모두 실측값으로 그린 SVG라 인터넷 없이 열립니다. 쪽 번호는 01부터라 최종 취합 때 맞춰 주세요.
